# 原生代码编辑器与项目文件

ZakoCoder 使用Sora原生编辑器，以Kotlin/Compose页面承载AndroidView；不使用网页编辑器。依赖版本、对应源码及许可证见[第三方说明](../THIRD_PARTY.md)。

## 项目与文件入口

项目库“添加项目”提供导入现有源码、创建空项目和克隆公开HTTPS仓库三个入口。导入通过Android系统目录选择器读取文档，在应用私有目录建立独立工作副本；SAF URI不是可猜测转换的Linux路径。导入不修改原目录，后续编辑也只作用于工作副本。

项目文件页支持新建文件、导入文件、浏览目录与打开文本。长按文件可打开、重命名、复制副本、复制项目相对路径或删除；目录支持打开、重命名、复制路径及确认删除。操作不覆盖同名条目，越界路径和不支持的链接受保护。

文件列表、编辑器加号与AI引用入口绑定当前项目及目录；切换身份立即丢弃旧条目，取消与迟到结果不能回填另一列表。读取失败明确显示原因并可原位重试，不显示成空目录。重试不写文件、不请求模型、不改变权限。

导出创建新目录，跳过依赖缓存、生成目录、`.git`和符号链接，不是无损备份或双向同步。卸载或清数据会删除工作副本、草稿和本地记录；先导出需要保留的代码。

## 编辑与语言

普通文件点击进入全屏编辑层，显示文件名、路径/未保存状态、行号、查找和保存；支持中文IME、选择复制、撤销/重做及区分大小写的字面量查找替换。

基础TextMate词法着色覆盖Kotlin、Java、JavaScript/TypeScript、Python、Shell、JSON、C/C++。其他受支持UTF-8文件按纯文本打开。着色不是完整解析或语义诊断；没有LSP、跨文件语义补全或编辑器内联AI补全。主题和词法资源离线加载。

最多8个编辑缓冲区，可从项目文件页或编辑器加号打开，多文件切换并关闭当前页签。同名文件页签使用可区分路径；当前路径与未保存状态仍可核对。关闭脏页签或离开未保存文档需明确选择保存、继续编辑或放弃。

## 文件范围与字节保留

支持UTF-8及UTF-8 BOM，保留原有LF、CRLF或CR换行和POSIX执行权限。单文件上限1 MiB、20000行、每行20000字符；超限、二进制或非UTF-8明确拒绝，不截断后保存。

符号链接、路径穿越、文件消失或不可读不能当成普通可写文档。原始字节SHA-256作为保存基线；内容变化与权限限制需显式处理，不能用当前页面显示内容覆盖未知磁盘状态。

## 保存与外部变化

只有显式保存才修改源文件；草稿持久化不等于保存源码。保存先写同目录临时文件并同步，保留权限，最终再次核对原基线后原子替换。应用内IO串行；外部进程不共享锁，最终检查与替换之间仍有竞争窗口，不提供跨进程事务隔离。

切回已打开文件、页面恢复前台或手动检查时，异步读取有界磁盘快照。变更或不可读取会提示，不自动替换当前buffer、撤销栈、光标或草稿；旧检查结果不得覆盖新文档身份或保存后的状态。

可只读比较本地缓冲与最近磁盘快照，切换缓冲全文、磁盘全文和Diff。该快照不保证持续实时；删除、链接、二进制或读取失败保持不可判断，而非空文件。确认重新加载前提示会丢弃本地编辑，未确认不覆盖。

保存仍以原始基线校验，不能把“已检查”视为写锁。发生外部冲突时保留缓冲，可复制、审阅或确认重载；不自动合并和静默覆盖。

## 草稿与生命周期

Activity重建保留应用级编辑内容、撤销栈和光标。停止输入约500ms后，将未保存内容、原始基线与光标写入应用私有草稿；进程重启后可从项目文件页重新打开继续编辑，最近约半秒尚未落盘的输入可能丢失。

草稿不写回导入来源、不自动修改源码，卸载或清数据会删除。恢复草稿后仍保留原保存基线；磁盘已变化时仍需解决冲突。原生编辑View释放时清理其分析资源，文档状态由应用持有。

AI未发送输入和命令配置表单的Activity重建保留属于各自界面状态，不等同于编辑器磁盘草稿，也不承诺冷启动恢复这些表单。

## AI引用、验证与审阅

编辑器AI入口引用选区，无选区时引用当前文件。最多4项、每项6000字符，标明来源、起始行、未保存及截断；发送当时快照，后续编辑不会自动更新附件。完整任务契约见[AI工作流](AI_WORKFLOW.md)。

项目命令执行使用磁盘源码，不自动保存编辑缓冲。命令页、确认框和验收页提示当前项目已加载页签的未保存数量；其他项目不计入，零个不证明没有未加载草稿。保存后需重新执行验证，先前退出0不能证明新草稿正确。

审批和历史变更使用全屏只读Sora审阅，可看原文、修改后、Diff与已知前后权限；正文未变化但权限改变会明确说明。只读审阅不会修改编辑缓冲或源文件，审批草案也不会提前写入磁盘。

检查点恢复会检查打开的编辑缓冲并阻止冲突覆盖；它有独立的捕获、保留和中断限制，不替代完整项目备份。详情见[AI工作流](AI_WORKFLOW.md)。

## Git边界

克隆只支持公开HTTPS地址，拒绝URL凭据、查询参数和片段，需先安装Ubuntu与Git。项目Git页面支持状态、显式初始化、选择文件暂存和以显式作者信息提交本地暂存区；不自动推送或设置全局作者。

该流程禁用提交钩子、签名与凭据助手；私有认证仓库、分支管理、合并及冲突界面尚未实现。超过500项修改不在UI提交，应在终端检查完整状态。目录概览隐藏VCS元数据不代表已经确认Git仓库存在或缺失。
