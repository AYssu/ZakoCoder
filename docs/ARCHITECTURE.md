# 架构与数据边界

自有业务采用 Kotlin + Compose，保留单个 `:app` 模块。`third_party/` 的终端库提供独立构建边界，来源及许可见[第三方说明](../THIRD_PARTY.md)。当前无后端、QuickJS 或插件运行时。

## 职责与调用

```text
MainActivity / Compose
  ZakoApplication → Workbench
    projects/  项目注册、SAF 导入导出、私有工作副本与清单检测
    editor/    编辑缓冲、文件基线、原子保存、草稿与语法资源
    runtime/   下载校验、解包、工具探针、安装计划与 guest 命令
    terminal/  PTY、输入输出、会话归属与前台服务
    ai/        模型配置、SSE、会话、上下文、权限、工具及检查点
    mcp/       加密服务配置、JSON-RPC、stdio/HTTP/SSE 与连接归属
    workflow/  项目命令配置、执行记录、日志与源码证据
    git/       Ubuntu Git 克隆、状态、暂存与本地提交
    settings/  运行与显示配置
```

UI 展示生命周期感知状态并派发事件，不直接执行网络、安装或创建进程。Workbench 属于 Application，持有跨页面操作与会话；原生终端 View 弱引用附着已有会话，不拥有进程生命周期。磁盘、SAF、网络及阻塞进程操作放在 IO 调度器，取消必须传播。

## 文件与存储

项目注册由 AtomicFile 保存，私有工作副本位于 `files/workspaces/<uuid>`；真实目录绑定另存版本化映射，不移动源码。统一目录解析供编辑器、文件工具与执行环境使用，绑定项目以显式 PRoot argv 挂载到 `/workspace/<uuid>`；解除绑定只移除登记和私有记录。外部目录不可访问时保留登记并报错，不回退到副本。选择项和普通设置使用 SharedPreferences。SAF URI 只交由文档提供者读写，不推测 Linux 路径。导入导出是有界复制，不隐式同步原目录。

ProjectApkInstaller 在用户确认后于 IO 线程生成有界 APK 缓存副本，拒绝目录穿越和符号链接，通过 FileProvider 向系统安装器授予只读 URI 权限。提供者只暴露 `cache/apk-install/`；未知来源许可和最终安装由系统界面确认，不直接暴露项目目录或静默安装。

EditorController 持有最多 8 个 Content 缓冲；EditorFileStore 限量读取 UTF-8，保存前检查原始字节摘要，写同目录临时文件、同步并保留权限后原子替换。草稿独立保存文本、基线及光标，只有显式保存修改源码。磁盘变化采样绑定文档与代际，不重设保存基线；外部进程不受应用锁约束，最终检查与替换间仍可能竞争。

AI 会话位于 `noBackupFilesDir/ai-history-v1`，检查点与恢复进度独立持久化；项目命令配置、记录与日志位于 `project-tasks-v1`，草稿位于 `editor-drafts`。这些内容不属于项目导出。数据有保留上限，详见[产品边界](PRODUCT.md)；存储格式变动必须兼容读取或明确迁移，不能静默清空数据。

## AI 请求与连续性

AiModelsController 管理配置元数据，AiConfigStore 原子保存配置并通过 Android Keystore AES-GCM 加密密钥。密钥不回显、不写入 SavedState 或项目导出；跨服务源复用要求显式处理。旧单配置兼容读取，首次管理修改写新目录；新目录存在时不复活旧配置。

ChatTransport 处理 HTTPS Chat Completions／SSE，禁止明文 HTTP 和重定向。模型发现与流式工具测试是显式操作；测试使用无项目副作用的探针工具，结果绑定输入及请求代际。活动任务期间禁止切换或修改配置。

AiController 持有单个活动任务，时间线、模型计划、工具草稿与实际事件分开建模。AiHistoryStore 的保存、切换及删除串行执行；异步历史与文件引用绑定项目、会话及代际，迟到结果不能覆盖新身份。首次请求前保存，运行中周期保存，最终保存失败可重试而不重放模型或工具；加载损坏不能通过重试写入覆盖。

AiContext、项目概览和规则加载受读取权限约束。成功轮次、失败进度及有损续接摘要分别保留预算；压缩保留原始需求及最近完整工具组。内置 Skills 从 APK assets 加载，项目 Skills 经受保护文件入口读取，均为用户级参考，不是权限或可执行插件。

McpController 保存设备级服务目录，使用配置代际和项目归属拒绝迟到调用。McpSession 串行初始化与 JSON-RPC 请求，保留嵌套参数和协议结果；后台读写限量，取消关闭连接和已验证归属的 guest 进程。配置保存与显式连接分离，工具调用仍通过 AiController 的权限与审计事件；服务输出不能创建授权。配置加密与限制见[AI 工作流](AI_WORKFLOW.md)。

## 工具、授权与证据

AiPermissionStore 独立保存项目默认规则及单工具例外。加载失败禁止工具，保存成功后生效；临时授权仅属于当前任务，结束或取消即清除，禁止规则优先。待审批的文件写入不提前执行；结构化修改检查读取基线、编辑占用及规则更新，获批命令始终运行在 guest 环境。

AiCheckpoints 记录有界文件、目录及权限状态，恢复前预检全部目标，逐文件原子替换并保存恢复进度。目录仅在没有未知子项时非递归删除；旧快照不补造目录历史。恢复不是跨文件事务，也不覆盖安装、网络及数据库副作用。

ProjectTasks 保存实际脚本、cwd、超时、来源、任务轮次、退出码及有界日志；运行中增量保存，重启后的未结束记录标记中断。日志采用完整快照发布，读取失败不等同于空日志。源码证据在有界范围内采样，权限或容量不足显示未知；历史验证结果不随文件修改自动成为当前验证依据。

## 运行与生命周期

LinuxRuntime 准备固定 guest argv，TerminalManager 管理最多四个项目会话；AI 终端工具经 Workbench 复用同一管理器，并校验项目归属。长期服务使用可见 PTY，普通 `run_command` 有明确超时，不用脱离的后台命令伪造持续服务。

DevelopmentService 提供前台通知与停止全部；仅在运行任务或会话需要时持有。通知状态查询不自动申请权限或更改系统开关。页面返回、切换和 Activity 重建不主动重启进程；系统回收后不保证继续运行，不自动重放副作用。

PRoot 是共享兼容环境，挂载多个项目，不构成安全隔离。取消只处理可验证属于本应用任务的进程树，不能使用全局 `killall`。环境路径、工具安装和供应链约束见[运行环境](RUNTIME.md)。

## 异步状态约束

目录列表、模型探测、依赖计划、编辑器磁盘检查与历史审阅都必须绑定实际身份。切换后先清除旧的可点击结果，取消旧请求，拒绝迟到完成；加载、失败、缺失和空状态分开表达。操作成功通过明确版本更新驱动刷新，不能依赖短暂 busy 布尔值被 UI 观察到。

实现规范见[开发与测试](DEVELOPMENT.md)，界面约束见[设计规范](DESIGN.md)。
