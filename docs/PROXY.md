# 网络代理

ZakoCoder 连接用户提供的外部 HTTP／SOCKS5 代理，用于模型请求、Ubuntu 镜像下载和支持代理的开发工具。Lite 与 Full 的代理能力相同；应用不再内置或启动代理内核，不导入机场订阅，也不管理代理节点。

## 配置与使用

进入「设置 → 网络代理」，填写代理地址并保存；留空表示关闭应用内代理。代理服务可以运行在同一台手机上，也可以运行在手机能够访问的电脑或服务器上。

| 类型 | 地址格式 | 认证 |
| --- | --- | --- |
| HTTP | `http://主机:端口` | 不支持用户名／密码。 |
| SOCKS5 | `socks5://主机:端口` | 可选 `socks5://用户名:密码@主机:端口`。 |

`127.0.0.1` 和 `localhost` 指当前手机；连接其他设备时填写其可达的 IP 或域名。端口必须与外部代理服务实际监听的端口一致。HTTP 代理可以转发 HTTPS 目标，但代理地址仍使用 `http://`；应用不会把 `https://` 代理端点自动降级为 HTTP。

保存配置不等于服务已就绪。请确认外部代理已启动、手机可以访问其监听地址，然后分别测试所需的模型接口和下载地址。代理服务的协议、认证方式和转发规则由该服务管理；应用不会自动安装或启动它。

## 生效范围

- 模型请求与环境镜像下载使用保存的代理。HTTP 代理与 SOCKS5 的支持范围不同，不能仅凭某个网页可打开判断所有服务都可用。
- 新建 Ubuntu 终端与项目命令继承代理环境变量。HTTP 配置导出 `http_proxy`／`https_proxy` 等变量；SOCKS5 配置导出 `socks5://` 形式的 `ALL_PROXY`。已有进程不会自动更新环境，请新建终端或重新运行命令。
- 应用的 SOCKS5 请求将目标域名交给代理解析；guest 工具如何解析域名取决于该工具。curl／git 对 `socks5://` 通常在本机解析，不能将应用请求的代理侧解析行为等同于全部终端命令。
- APT 等只识别 HTTP 代理的工具不会使用 SOCKS5。Android SDK manager 和 guest Gradle JVM 仅支持 HTTP 或无认证 SOCKS5，不能继承 Android 应用的 SOCKS5 认证器。
- 这不是全设备 VPN；其他应用的流量不会因为这里保存了代理而自动转发。系统浏览器等外部应用使用自身网络设置。

## 凭据与诊断

SOCKS5 凭据由 Android Keystore 加密保存，界面打码且不写入日志。相同端点的编辑不会要求回填已保存的密码；更换端点时请明确配置新服务的认证信息。含认证的 `ALL_PROXY` 对 guest 进程可见，不要将完整环境、代理地址或命令历史直接发到公开 Issue。

连接失败时先确认地址、端口、认证和外部代理的运行状态，再检查手机到代理服务器的网络是否可达。使用助手的 `/doctor` 可导出脱敏诊断包；提交前仍需检查附件中是否包含个人信息。代理失效时可以清空配置恢复直连，或改成已就绪的外部代理。

## 从旧版升级

新版不再绑定、启动或更新旧独立内核插件，也不会擅自卸载设备上已安装的插件。升级时只清理能够与本应用旧内核端口标记准确匹配的 `socks5://127.0.0.1:端口` 代理端点，并提示重新配置外部代理，避免失效的本地桥接阻断请求。

用户手动设置的 HTTP／SOCKS5 端点及其加密凭据继续保留，包括 `127.0.0.1` 与 `localhost` 地址。原来的订阅或节点无法直接作为外部代理地址使用；请先在其他代理软件中启动所需服务，再填写它提供的 HTTP／SOCKS5 监听地址。
