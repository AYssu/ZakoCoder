# 网络代理与机场订阅 · UI 设计方案

> 版本 v1.0 ｜ 设计基准 360dp（375pt 等比）｜ 覆盖页面：网络代理（手动 / 机场订阅）｜ 依据：`docs/DESIGN.md` 主题与字阶、`mobile-ui-design-kit` 布局规则

## 一、设计命题

**为谁**：需要在手机上通过自建代理或机场订阅访问模型服务、Ubuntu 工具链的开发者；经常在通勤/设备旁快速切换节点。
**解决什么**：把「粘贴订阅链接 → 判断这是单节点还是机场 → 导入节点 → 选中一个可用节点 → 立即生效」压缩成一屏内可完成的流程，并如实区分可用与不支持的协议。
**视觉要传达**：清晰（状态先行）、紧凑（列表密度高但不拥挤）、可追溯（当前节点/来源/更新时间可见）。
**设计策略一句话**：状态卡先回答「现在走哪条路」，机场区用「识别 → 结果徽标 → 节点列表 → 唯一主 CTA」完成决策，危险/低频操作降级。

## 二、信息架构

| 顺序 | 区块 | 信息目的 | 用户动作 |
| --- | --- | --- | --- |
| 1 | 顶部栏：返回 + 标题「网络代理」 | 明确所在页面 | 返回设置 |
| 2 | 当前状态卡 | 现在是否走代理、端点（打码）、是否含凭据 | 只读 |
| 3 | 模式分段控件：直连 / 手动代理 / 机场订阅 | 三种来源互斥 | 切换模式（不立即发请求） |
| 4 | 手动代理表单（仅手动模式） | 粘贴 http/socks5 端点（可含凭据） | 保存并启用 |
| 5 | 机场订阅区（仅机场模式）：链接输入 + 「识别链接」 | 判断链接类型并显示结果 | 识别 / 粘贴 |
| 6 | 识别结果 + 节点列表 | 是否机场、节点数、可用数、协议 | 选择可用节点、查看不支持原因 |
| 7 | 固定主 CTA：保存并启用（选中节点）/ 移除订阅（次级危险） | 完成切换或清理 | 生效 / 二次确认移除 |

**导航模型**：设置页「网络代理」行进入独立二级页（与模型配置/更新页一致），返回保留草稿；不新增底部 Tab。

## 三、逐区块布局

### 3.1 顶部栏（高 56dp）
返回图标 48×48dp 触区；标题 19sp/600；右侧无操作。不显示网络请求按钮。

### 3.2 当前状态卡（圆角 12dp，内距 16dp，卡片间距 16dp）
- 第一行：状态圆点（8dp，直连=次要灰、代理=主蓝、异常=错误红）+「直连 / 手动代理 / 机场节点」+ 右侧「已生效」辅助文字 12sp。
- 第二行：当前端点 12sp 等宽或打码文本，单行省略，点按可复制（复制的是打码后展示，不含密码）。
- 第三行（可选）：「来自机场 · 节点名」辅助 12sp，超出省略。
- 主色只用于状态圆点与选中态，面积 < 10%。

### 3.3 模式分段控件（高 48dp，圆角 12dp，三段等分）
文案「直连 / 手动代理 / 机场订阅」，14sp/500；选中 primaryContainer 底 + primary 文字 + 1dp 描边，未选中 surface + outlineVariant。切换只改本地状态，不触发网络或保存。

### 3.4 手动代理表单
- 输入框高 48dp、圆角 10dp、内距 12dp，label「代理地址」；placeholder `http://主机:端口` / `socks5://[用户:密码@]主机:端口`。
- 说明 12sp 次要文字两行内：支持 HTTP/SOCKS5，SOCKS5 可带凭据并加密保存；留空=关闭。
- 错误 13sp error 色，紧跟输入框下方，不换页。
- 主按钮「保存并启用」48dp 全宽；保存中禁用并显示 12sp「正在保存…」。

### 3.5 机场订阅区
- 输入框同上，label「订阅链接」，placeholder「https://…」；右侧内嵌 48dp 图标按钮「粘贴」（读剪贴板，用户显式点）。
- 识别按钮「识别链接」48dp 全宽次级按钮（描边）；识别中按钮内 16dp 转圈 +「正在识别」。
- 说明 12sp：仅支持 HTTPS；订阅链接可能含口令，只在点击时联网并加密保存。
- 缓存存在时显示「上次导入：MM-dd HH:mm · N 个节点」+ 次级文字链「刷新订阅」「移除订阅」。

### 3.6 识别结果与节点列表
- 结果徽标行：胶囊标签（高 22dp、内距 8dp、圆角 4dp）：机场订阅（主色底 8%）/ 单节点（中性）/ 暂不支持（警告）/ 无法识别（错误）；右侧辅助文字「12 个节点 · 8 个可用」。
- 单节点结果：一张卡片显示节点名、协议标签、host:port，主 CTA 直接为「保存并启用」。
- 节点列表：每行最小高 56dp，内距 12dp，行间 1dp 分割线；左侧 20×20 协议图标位（或 2 字协议短标），主行 14sp 名称（最多 2 行截断），次行 12sp `host:port` + 协议名；右侧单选框（可用节点）或「暂不支持」标签（灰，不可选）。
- 可用 = SOCKS5（可带用户名密码）或 HTTP（无凭据）；`https://`（TLS-to-proxy）、SOCKS4、VMess/SS/Trojan/VLESS/Hysteria/TUIC 等显示「暂不支持」，点击给一行说明「当前版本仅支持 HTTP/SOCKS5 节点」。`https://` 节点不会被降级成明文 `http://` 写入设置。
- 列表最多一屏内滚动，页面级滚动；固定底部区存放主 CTA，列表底部 padding ≥ 主 CTA 高度 + 24dp。

### 3.7 固定底部操作区（高 56dp + 安全区 24dp，上描边）
- 唯一主 CTA「保存并启用」：未选可用节点时禁用。
- 次级「取消」文字按钮 48dp 触区。
- 「移除订阅」放页面内列表下方，error 文字按钮 + 二次确认对话框，不占底部主位。

## 四、色彩

沿用 `docs/DESIGN.md` 主题色，不另起视觉体系：

| 语义 | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| 页面底 | `#F5F7FA` | `#0B0F14` | 60% |
| 卡片/表面 | `#FFFFFF` | `#151B23` | 20% |
| 主色 | `#2563EB` | `#4C8DFF` | 主 CTA、选中态、状态点（10%） |
| 主文字 | `#0F172A` | `#E6EDF3` | 标题/正文 |
| 次要文字 | `#5B6B82` | `#9BA7B4` | 说明/来源 |
| 成功 | `#16A34A` | 同 | 「已生效」「可用」 |
| 警告 | `#F59E0B` | 同 | 「暂不支持」「需刷新」 |
| 错误 | `#DC2626` | 同 | 识别失败、移除操作 |

## 五、字体与排版

沿用现有字阶：页面标题 19sp/600（弹层）→ 本页用 20sp/600；区块标题 16sp/600；正文 14sp/400（行高 21sp）；辅助 12sp/400；节点名 14sp/500；协议标签 12sp/500；按钮 15sp/600。不使用 11sp 以下正文；说明允许两行，超长省略。

## 七、交互与状态

| 场景 | 表现 |
| --- | --- |
| 加载（识别/刷新） | 结果区骨架：3 条 56dp 灰块（保持列表轮廓），不使用整页转圈 |
| 空（无订阅） | 图标 56dp + 「还没有导入机场订阅」+ 说明「粘贴订阅链接后点识别链接」 |
| 错误 | 原位显示原因 + 可执行操作：HTTPS 不合规→改链接；连不上→重试；内容无法识别→检查是否为订阅链接；过大→换小订阅；均提供「重试」按钮 |
| 不支持协议 | 节点行灰化 + 「暂不支持」标签，点击提示「当前版本仅支持 HTTP/SOCKS5 节点」，不写入设置 |
| 超长内容 | 节点名 2 行截断；`host:port` 单行省略；链接展示只保留 host，参数显示为 `•••` |
| 点击反馈 | 按钮按下立即变色；行选中即时更新单选与底部 CTA 可用性；识别/导入成功后预选第一个可用节点，但必须点「保存并启用」才写入设置 |
| 键盘 | 输入聚焦时底部 CTA 随 IME 上移；返回键先收键盘再退出页面 |
| 下拉刷新 | 节点列表不默认下拉；刷新是显式按钮，避免误触联网；识别失败重试识别，刷新失败重试刷新 |

## 八、安全与边界（产品可见说明）

- 仅接受 HTTPS 订阅链接；导入/刷新必须由用户显式点击，打开页面不发请求、不自动重试。
- 订阅链接可能含口令：展示打码、日志不输出完整链接；订阅内容与节点凭据用 Android Keystore 加密保存。
- 仅导入后可用的 HTTP/SOCKS5 节点；HTTP 节点只有无凭据时才可启用（应用 HTTP 代理路径不支持账号密码），带凭据的 HTTP 节点与其他协议一样标注「暂不支持」，不伪装可用；`https://`（TLS-to-proxy）与 SOCKS4 同样不支持，且不会降级为明文 HTTP。
- 订阅内容由应用直连下载，不走已配置的代理（避免先有节点才能取订阅的循环依赖）；导入成功后只预选第一个可用节点，仍由用户点「保存并启用」。
- 单节点但协议不支持时归入「暂不支持」并列出该节点；非 ASCII/IDN 主机不作为可启用节点（写回设置会失败，直接标为不支持）。
- 选中节点后写入现有代理设置并立即生效；guest 终端 `ALL_PROXY` 若带凭据对 guest 进程可见（沿用现行说明）。
- 数量/大小上限：响应 ≤ 2 MiB（超出拒绝并提示）；最多展示 512 个节点（超出按输入顺序截断并在界面显示有效节点数）；单节点但协议不支持时归入「暂不支持」而不是「单节点」。

## 九、交付备注

- 图标沿用现有 `WorkbenchIcon`/`Glyph` 体系；协议用 2–3 字短标（HTTP/SOCKS/VM/SS/TR），不引入新图标库。
- 适配：竖屏为主，窄屏 360dp、130% 字体、亮暗主题、键盘必须复核；列表底部留出主 CTA 高度。
- 截图证据：识别中、识别成功（机场）、单节点、错误、不支持协议、空订阅，亮/暗各一组，至少覆盖 360dp 与 130% 字体。
- 待确认：机场节点延迟/测速、订阅自动更新不在本版范围。
