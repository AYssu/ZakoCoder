# 能力包管理与 SSH 配置设计

版本：2026-10-30。基准宽度 360dp；Kotlin + Compose 原生实现。沿用项目主题及用户指定的 mobile-ui-design-kit 布局、字阶与安全区规则。本设计描述交互规范；实际通过的设备检查与截图由对应验收记录说明。

## 需求与设计命题

面向在手机上维护项目的开发者。用户需要知道当前项目允许助手做什么、如何配置可选能力，并在需要时进入具体操作界面。

关键词是明确、克制、可控。先选能力，再配置连接或目标；系统权限与实际操作审批分别呈现。能力按项目启用，两包均默认关闭。关闭能力后，模型请求不再携带对应工具定义及专属说明。

## 导航与信息顺序

| 顺序 | 区块 | 信息目的 | 用户动作 |
| --- | --- | --- | --- |
| 1 | 设置的开发能力组 / 助手更多菜单 | 提供统一入口 | 打开能力包 |
| 2 | 当前项目 | 解释配置归属 | 核对项目名 |
| 3 | Android 屏幕识别与操作卡片 | 说明节点、截图和操作能力 | 为此项目启用；进入屏幕配置 |
| 4 | SSH 远程开发卡片 | 说明连接、文件与长任务能力 | 为此项目启用；进入 SSH 配置 |
| 5 | 加载与权限说明 | 解释默认关闭、按需加载及审批 | 阅读 |

使用现有 WorkbenchSheet 底部面板，支持纵向滚动、键盘避让及系统底部安全区。设置和助手共用同一入口与配置界面，不在聊天输入区增加常驻按钮。

## 能力卡片

卡片采用单列，16dp 内距、12dp 内部间距、16dp 圆角及 1dp 描边。标题使用 titleSmall，说明 bodyMedium，归属和权限说明 bodySmall。图标容器 40dp；开关点击区至少 48dp。

标题和说明可以换行，不以省略号隐藏能力范围。开关下显示“仅此项目”。关闭状态仅显示概要；开启后显示权限提示和一个描边配置按钮。按钮文案为“配置屏幕操作”或“配置 SSH 连接”，避免将完整能力标题塞入按钮造成层级混乱。

未选择项目时仅呈现引导，不展示可操作开关。加载或保存中禁用开关和配置入口；错误在当前面板内显示，保留页面状态。

## SSH 配置

信息顺序：连接信息 → tmux 选项 → 保存 → 连接状态 → 主机身份。

连接信息包含主机、端口、用户名、远程项目绝对路径与认证方式。端口固定宽 112dp，与用户名同排；其余输入单列满宽。密码和私钥二选一；私钥可附带口令。密码和口令默认隐藏，提供文字形式的显示/隐藏操作，不以含义模糊的图标表达。

配置草稿与已保存配置不同，或存在新的凭据时，必须先保存，之后才允许测试连接。表单完成或修改后仅“保存连接配置”为实心主按钮，其余连接操作采用描边或文字按钮。SSH 配置不直接发起网络或进程操作，只通过回调交给控制器。

凭据是写入型字段：页面只接收“已保存”标志，永不回填保存的密码或私钥，不使用 rememberSaveable。保存成功后外层递增 configRevision，清空凭据草稿并恢复隐藏状态；保存失败保留用户输入。更换认证方式立即清空当前凭据草稿。草稿的 toString 固定返回 redacted，避免意外日志输出。

## 主机指纹

首次连接展示算法及可选择复制的 SHA-256 指纹。用户通过可信渠道核对后点击“确认指纹并继续”。确认前不应发送认证凭据。指纹发生改变时显示错误语义说明并禁用继续按钮；用户核实后可先清除已信任记录，再重新测试与核对。UI 不自动信任新主机或变化的指纹。

连接测试期间显示进度及当前状态，并提供始终可用的“停止当前连接操作”入口；失败原因留在页面，不只弹成功/失败提示。短连接验证成功显示“连接验证通过”，不将已经关闭的测试连接表现为持续在线。SSH 主机配置与连接状态由控制器提供，UI 不构造成功记录。tmux 是 SSH 内的可选长任务管理能力，检测不可用时明确提示，普通命令能力仍单独说明。

复用 WorkbenchColors 与 WorkbenchDarkColors，不增加第三套页面配色。

## 边界与验收

- 默认关闭的两个能力开关、按项目归属和无项目空态。
- 开启后才可配置屏幕目标或 SSH；开启开关不会自动授予 Root、无障碍或截图分享权限。
- SSH 配置字段、密码/私钥选择、基础端口与绝对路径校验、保存后才能连接。
- 首次指纹确认、变化阻断、已信任指纹清除及 tmux 状态。
- 360dp 与 130% 字体下覆盖日间/夜间原生界面截图，关键底部操作无裁切。
- 纯 UI 测试只使用明确的测试夹具，不连接真实服务器，不读取用户项目或已有凭据；真实 SSH 传输与工具加载另由集成验证证明。

关于页额外提供 JSch 开源许可证入口，读取 APK 内原始 assets/licenses/JSch-BSD.txt；文件读取在 IO 调度器执行，许可证组件名、版本和 BSD 声明可以核对。

对应实现为 CapabilityPackagesSheet、SshPackageSheet、SettingsPage 的许可证面板和 CapabilityPackagesUiDeviceTest。截图归档与通过状态以实际设备运行结果为准，不能由这份设计文档推定已通过。
