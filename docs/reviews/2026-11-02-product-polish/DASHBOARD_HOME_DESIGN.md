# 用量与项目库界面设计

本说明描述本次原生 Compose 变更；验证结果和截图由实际设备检查后补充，不将设计当作已验收。

## 需求与调性

对象是在手机上持续维护项目的开发者。用量面板回答「何时发生请求、调用量如何分布」，主页回答「接着处理哪个项目、当前环境是否可用」。关键词：克制、可扫读、可追溯。保留原生导航和既有数据来源，不新增统计后台或自动执行行为。

## 信息结构

用量保持日期、项目、模型筛选 → 范围和读取状态 → 汇总 → 趋势 → 模型分布 → 数据范围说明。趋势可选择请求、Token、工具，月视图按本地自然日分桶、日视图按本地小时分桶；夏令时日可能有 23／25 个小时，时间带偏移量以区别重复时段。图表只使用已筛选账本，不使用有条数上限的请求详情。

柱形采用主题主色，非选中列为 75% 主色混合（不再使用低对比的 35%）；选中列使用完整主色及浅底。图表有统一基线和四条水平参考线，显示顶端量级和首尾时间。点击图中任意横向时段可直接选中（包括空时段），按整个时段宽度命中而不要求点中柱形本身；选中列显示浅色底并更新实际数值。保留 48dp 左右按钮用于精确逐时段查看及无障碍操作，不强迫用户连续点击至月中日期。模型分布按请求次数降序，最多展示五项并说明其余数量；比例的分母包含全部模型。

请求和工具次数允许为零；缺失、非法或溢出的服务 Token 不造零。Token 视图保留「仅合计已返回输入输出」说明，与现有回报覆盖数和账本不完整提示配合使用。读取失败或加载中不展示图表；没有记录时沿用可解释空态。

项目库常驻搜索，不需要先点击图标。当前选中项目排在前面，卡片显示真实选中状态及正在运行的终端数，不捏造最近访问时间。列表卡片顺序为状态 → 项目名称及类型 → 存放方式与真实绑定路径 → 三个操作；浏览文件为主要入口，助手和终端为次级入口。更多按钮仍保留项目名称的无障碍标签。空项目库只保留空态主操作，避免同时出现两个添加按钮。

## 样式与边界

沿用仓库亮暗主题：亮色背景 #F5F7FA、表面 #FFFFFF、正文 #0F172A、主色 #2563EB；暗色背景 #0B0F14、表面 #151B23、正文 #E6EDF3、主色由现有主题提供。中性表面为主体，主色仅用于选中、柱形和主要操作。容器圆角 12dp、1dp 主题描边，内距 16dp；图表高度 132dp，区块间距 12／16dp。

保留已有字阶和至少 48dp 操作热区。长名称两行省略、绑定路径两行省略；环境标题和工具摘要分别展示并可换行。360dp、130% 字体、亮暗模式复用相同结构。统计值、说明和按钮使用语义文字；不依赖柱形颜色表达唯一信息。

## 验证入口

- `AiUsageChartsTest`：月份边界、夏令时、未知／零／溢出、筛选来源、模型分布稳定排序。
- `UsageChartsHomeUiDeviceTest`：360dp、130% 字体亮暗模式；趋势指标切换、直接点击首日及月中空时段、箭头逐时段查看，项目浏览、终端、更多回调；截图输出到隔离测试应用 `cache/ui-review/product-polish/`。
- `ProductDashboardFullPageDeviceTest`：使用全新文件／偏好存储的真实 Workbench 和 ZakoCoderApp，覆盖完整首页导航、搜索、设置到用量面板、模型筛选；360dp／130% 字体日夜截图，系统栏按主题配置，不读取现有项目或凭据。
- `AiUsageDashboardDeviceTest`：已有真实面板筛选、空／加载／错误／保留范围状态回归。

此文档不替代实际构建、交互测试、截图与独立体验审查。
