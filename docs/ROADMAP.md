# 路线图

当前为 `0.1.0-dev` 开发版本，没有正式发行日期。下列“已有基础”表示当前代码提供相关能力，不代表全部设备、工具链或模型服务已经验收；具体边界见[产品说明](PRODUCT.md)。

## 已有基础

- Kotlin + Compose 原生工作台、双主题、项目库、SAF 工作副本导入导出及文件管理。
- Sora 编辑器、多文件缓冲、私有草稿、磁盘冲突检测、代码引用与只读差异审阅。
- 固定 Ubuntu ARM64 安装、工具包选择与检测、根依赖计划、真实多会话 PTY 和本机浏览器预览。
- Chat Completions／SSE、命名模型配置、项目工具权限与审批、可观察工具执行及内置／项目 Skills；独立扩展管理和有界 MCP 工具／资源／提示调用。
- 本地会话、失败进度续聊、有损上下文压缩、受保护任务检查点、持久命令记录及基于实际退出码的验收。
- 公开 HTTPS Git 克隆、状态、选择暂存与本地提交；贡献流程、仓库检查和 CI。

## 近期优先项

| 方向 | 完成标准 |
| --- | --- |
| 可靠连续性 | 失败、取消、存储异常、重启和迟到请求均有明确状态，用户可恢复已存进度，不重放副作用、不覆盖后续修改。 |
| 移动端操作 | 核心流程在窄屏、亮暗、大字体、键盘下可完成；补齐 TalkBack、焦点顺序和横屏覆盖，结果以实际交互验证为准。 |
| 环境兼容 | 明确不同 Android／厂商、工具链及项目版本的适用范围，处理安装与依赖失败，不把基础工具就绪视为项目可构建。 |
| 验证与审阅 | 文件、权限、日志、命令来源和源码适用性可定位；缺失、未知、失败与未验证不能被误报为通过。 |
| 数据兼容 | 迁移与升级保留项目、配置、草稿及会话；损坏数据不静默覆盖，有清晰恢复或导出路径。 |

## 首次正式发行门槛

- 审查已接入的 PRoot／loader 自编译供应链、对应源码分发材料、许可与设备覆盖证据，才解除 Release 构建门槛。
- 明确 applicationId、命名、版本策略、签名保管和升级兼容范围。
- 配置真实可用的安全报告渠道、分支保护、必要 CI 检查和审查权限。
- 在干净环境构建并审查制品、权限、许可证与摘要，公开说明已支持的平台和已知限制。

完整要求见[发布流程](RELEASING.md)。上述条件未完成前，不公开分发当前验证 APK 或宣称生产就绪。

## 尚未承诺的能力

x86_64 模拟器、完整 Android／Flutter 手机工具链、LSP 与语义补全、私有 Git 认证及分支／冲突界面、云同步、SSH 远程工作机、多任务调度和插件市场均不属于当前能力保证。新增方向需先明确用户场景、维护成本、数据与权限影响，再决定范围与验收标准。
