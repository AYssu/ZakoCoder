# 应用内更新

设置中的「应用更新」从本项目 GitHub Releases 查询，正式版默认只查询正式版，Beta 默认包含预发布与正式版，可手动切换。版本按 SemVer 比较，不按发布日期排序，不降级。非发布开发版本没有可比较的 SemVer，自动检查停用，手动检查不会声称可升级。

自动检查最多每天成功一次，失败后至少间隔 5 分钟；不自动下载或安装。相同版本暂缓后 7 天再次提醒，手动检查仍可查看。公开版本查询与下载访问 GitHub，未读取模型服务商配置或密钥。当前最多检索最近 90 个 Releases。

仅下载官方命名的 ARM64 APK 与其 SHA256SUMS。检查下载大小、摘要、包名、发布版本、递增 versionCode、最低系统版本及当前签名集合完全一致。签名轮换暂不自动接受，需要独立迁移。测试包与正式包包名不同，下载可用于拒绝校验测试，不能覆盖安装。网络下载可以取消并重试，未完整校验的文件不进入安装流程。

完整 APK 保存在应用私有目录，重启后重新校验并恢复安装入口。安装使用已有 FileProvider 向系统临时授予读权限，不需要存储权限。Android 的「允许来自此来源的应用」授权由用户确认，返回后恢复安装；最终系统安装确认不能由应用绕过。安装失败可返回页面重试，不清除用户数据。

开发验证应覆盖：版本/渠道选择、摘要格式及重复行、恶意来源拒绝；真实发布下载；断网、取消、重试；不匹配包名/签名/低版本拒绝；未知来源授权往返与进程重建；系统确认覆盖升级；日夜、窄屏和大字体界面。测试结果由当次 PR 记录，本文不将未执行的设备场景标记为通过。
