# Beta 测试

首个计划版本为 **0.1.0-beta.1**，面向愿意反馈问题的 Android ARM64 用户。请以仓库 **Releases** 中实际存在且标为 **Pre-release** 的版本为准；本文不是已发布声明。

## 下载与安装

1. 打开 [ZakoCoder Releases](https://github.com/AYssu/ZakoCoder/releases)，选择 Beta 预发布，下载 ARM64 APK 和 `SHA256SUMS.txt`。构建信息在发布正文的折叠详情中；完整源码使用该页指向本次固定提交／标签的 **Source code** 归档。
2. 按摘要核对下载文件。系统提示时，仅为你使用的浏览器或文件管理器开启安装未知应用权限。
3. 打开 APK 安装。首次进入先创建或导入一个可用于测试的项目，再按需要安装 Ubuntu 和开发工具；模型服务由你配置。

本次 Beta 使用 Release + R8 构建，应用不可调试，但默认沿用仓库 CI Debug 签名（可选自有签名），并非正式长期发布证书。相同 CI 签名、同一包名和更高 versionCode 的 Beta 可以覆盖对应 Debug 安装；本地或其他来源的 Debug 签名可能不同。已有安装提示签名不一致时，不要直接卸载或清数据；先导出重要项目并确认备份范围，再按发布说明处理。应用私有会话、草稿、设置和凭据不包含在普通项目源码导出中。后续同签名、更高 versionCode 的 Beta 才能覆盖更新；更新应用不会自动替换 Ubuntu。

Debug 测试包仍可从 **Actions → Build Debug APK → Artifacts** 获取，保留 14 天，下载需登录 GitHub。默认签名的 Beta 与该入口复用同一仓库 CI 签名；未来若切换正式密钥，将另行说明升级或迁移方式。

## 首批测试范围

- Beta APK 面向 **ARM64**。Android 11–17 为本轮系统测试范围，另含 Android 12L；已完成的广泛矩阵使用 AOSP **x86_64** 模拟器，ARM64 真机主要为 Android 13。详见[实际结果](ANDROID_COMPATIBILITY_RESULTS.md)。
- 模拟器基线不等于各厂商真机全部兼容。后台省电、目录授权、键盘和文件提供者行为可能不同；Beta 自动检查使用 API 35 x86_64 的同签名 R8 QA 包，并校验与公开 ARM64 包的 DEX／资源／assets 一致；公开 ARM64 Release 包的真机安装、同签名升级和终端／HTTP 冒烟尚未完成。最终本地 API 35 R8 QA 已完成项目创建、编辑保存、重启与配置持久化及 4 张日夜截图，并核对 QA 与 ARM64 候选包的代码／资源、共有原生制品、版本和证书一致；GitHub Actions 尚未实际运行。以该次发布记录为准，不把 QA 检查等同于 ARM64 实测。
- Android 8 的完整 Ubuntu／模型网络链路尚未验证通过，首批 Beta 不作完整支持承诺。16 KiB 页设备尚无实际运行验证。
- x86_64 仅用于基础系统兼容性验证，不提供完整 Android SDK／NDK 工具包承诺。

建议先用副本体验。绑定本地目录会直接修改原文件；导入副本不会回写原目录。PRoot 兼容 Linux 工具，但不是安全隔离边界。向模型发送任务时，项目内容及附件会发送到你配置的服务；核对权限审批与变更后再接受修改。

## 建议体验路线

1. 创建或导入项目，编辑一个文件并保存；退出重进后检查项目、草稿和会话。
2. 按需安装 Ubuntu 与 Python／Node 等工具，打开终端运行项目；启动 HTTP 服务并通过手机浏览器预览。
3. 配置有额度的模型服务，完成一次“阅读文件 → 修改 → 执行项目验证 → 审阅差异”的任务。收费和服务限制由所选供应商决定。
4. 试用文件引用、长回复、Skill／MCP 及 Git；涉及密钥、私有仓库和外部服务时自行选择测试资料。

不要求你上传测试项目、凭据或完整会话。检查点不能撤销依赖安装、网络请求、数据库等外部副作用。

## 反馈问题

通过仓库 Issues 反馈，建议包含：

- Beta 版本与 versionCode、手机型号、Android 版本、问题发生页面。
- 最短复现步骤、预期结果和实际结果；是否每次出现。
- 与问题相关的脱敏报错或截图；网络问题可写协议和供应商名称，不要提供 API Key、Authorization、SSH 凭据或私有源码。
- 涉及环境时，说明 Ubuntu／开发工具安装状态；涉及升级时，说明旧版本及安装渠道。

安全漏洞请按 [SECURITY.md](../SECURITY.md) 私下报告，避免公开可利用细节。数据异常先保留原文件和脱敏错误信息，不要反复清数据尝试恢复。
