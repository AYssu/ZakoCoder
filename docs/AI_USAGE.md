# 请求与用量

助手的请求详情提供当前会话汇总，设置中的「用量统计」可按日、月、项目和模型筛选本机记录。输入、输出、合计及服务报告的缓存分别显示，缺失用量显示未知，不补成零。缓存已包含在输入中，不再次加到合计。上下文展示最近请求估算及配置容量，不作为账单。

聊天下方的用量按任务独立保存在本机会话中，包括输入、输出、缓存、响应速度，以及该任务最后一次主请求的上下文估算与当时容量。重启、切换模型或请求详情滚动淘汰不会清除这些任务统计；子任务和压缩请求计入用量，但不替换主请求的上下文。JSON 对话导出／导入保留这些汇总。

任务统计与会话一同保留，最多保留最近 512 轮；完整请求详情仍只保留最近 32 条，并受正文容量限制。旧版会话只能根据仍保留的请求补回已有统计，已被淘汰或服务未返回的用量保持未知，不用字符数或最新任务代替。

记录独立于会话详情，最多保留近 730 天，各 10,000 条请求与工具事件；超出后页面说明保留范围。启用前的旧会话不反推补记，跨设备不合并。每个请求尝试、自动重试和压缩请求分别计数；工具总数包括待审批、拒绝及未执行事件，已执行数单列。账本仅保存身份、时序和用量，不保存提示词、正文、工具参数或密钥。保存失败会提示，不能将暂时可见数值视为完整统计。

聊天轮次下方以单行显示输入、输出、合计与上下文；宽度不足时收起次要字段，点击可查看时间、速度、缓存及完整用量。缓存比例仅在同一范围的输入及缓存值可比较时计算；少报字段时保留未知状态。字体随系统缩放。

## 消息操作

点击用户消息或助手消息的更多入口，可复制、编辑并重新生成、重新生成及查看会话请求。运行中不可重新生成。重新生成先确认，在新会话分支重新发送该轮，原会话保留；文件、终端、安装和外部副作用不会回滚。已记录的原始输入、文件引用和图片一起带入；旧版历史缺少原始引用边界时按原显示文本处理，超长文本需要先编辑精简。

## 自定义系统提示词

模型配置的自定义系统提示词放在应用固定编码规则、启用能力说明之后，在本轮动态权限及对话之前，不覆盖固定权限边界。保存后用于之后的请求。稳定文本有利于保留相同前缀；修改提示词、工具集合或权限说明会改变相应前缀，实际缓存是否命中以及统计是否返回仍由服务决定。

## 导出诊断包

遇到一直停在 Thinking、连接失败、工具调用中断或后台任务异常时，在助手输入 `/doctor`，选择「导出诊断包」，再选择保存位置。无需先停止任务、配置模型或选择工作区；此操作不调用模型，也不会自动上传。反馈时附上 ZIP、问题发生的大致时间及复现步骤即可。

诊断包包含应用版本、设备型号及 Android 版本、网络连接类型、通知和电池优化状态、近期系统进程退出原因（Android 11 及以上）、当前对话的任务阶段、上下文预算、请求统计、工具状态，以及最近的运行事件。事件覆盖请求开始、响应头、首条数据、流式进度、重试、任务与工具结果、前后台切换、后台服务、Ubuntu／工具安装、终端生命周期、SSH 和 MCP 连接阶段。错误只保存固定类别；诊断提示不等同于已确定故障原因。 任务快照同时包含累计请求、工具、Token 与耗时，以及已识别的白名单停止原因。文件读取与搜索事件使用任务内随机操作分组标识：同一组的开始和完成是状态变化，不算执行两次；不同调用若参数相同可关联比较。分组不导出路径、搜索词、文件内容、参数或它们的固定哈希，不跨任务追踪。

默认不导出聊天或思考正文、源码、命令、工具参数和输出、模型服务地址、SSH 主机、请求头、凭据、截图或原始 logcat；工作区和会话身份使用摘要。设备型号、时间及用量仍可见，分享前可以自行检查。项目源码或会话内容确有必要时，另由用户选择提供，不混入诊断包。

包内 `report.json` 是当前状态与最近至多 32 条请求、128 条工具记录，`events.jsonl` 是跨对话的近期固定事件，`README.txt` 解释口径。事件默认在本机有界记录：最多两个 256 KiB 文件，保留近 7 天，队列满或写盘失败会计数；强制结束进程可能丢失尚未落盘的末尾事件。新版本启用前的历史事件不会补造。诊断包临时快照最多保留 8 份、每份不超过 2 MiB，超时或取消的遗留快照在一小时后、下次准备导出时清理。保存或取消后清理对应快照；保存失败时可重新导出。
