# 请求与用量

助手的请求详情提供当前会话汇总，设置中的「用量统计」可按日、月、项目和模型筛选本机记录。输入、输出、合计及服务报告的缓存分别显示，缺失用量显示未知，不补成零。缓存已包含在输入中，不再次加到合计。上下文展示最近请求估算及配置容量，不作为账单。

记录独立于会话详情，最多保留近 730 天，各 10,000 条请求与工具事件；超出后页面说明保留范围。启用前的旧会话不反推补记，跨设备不合并。每个请求尝试、自动重试和压缩请求分别计数；工具总数包括待审批、拒绝及未执行事件，已执行数单列。账本仅保存身份、时序和用量，不保存提示词、正文、工具参数或密钥。保存失败会提示，不能将暂时可见数值视为完整统计。

聊天轮次下方第一行显示输入、输出、合计，第二行显示时间、速度及缓存。缓存比例仅在同一范围的输入及缓存值可比较时计算；少报字段时保留未知状态。小屏可横向查看，字体随系统缩放。

## 消息操作

点击用户消息或助手消息的更多入口，可复制、编辑并重新生成、重新生成及查看会话请求。运行中不可重新生成。重新生成先确认，在新会话分支重新发送该轮，原会话保留；文件、终端、安装和外部副作用不会回滚。已记录的原始输入、文件引用和图片一起带入；旧版历史缺少原始引用边界时按原显示文本处理，超长文本需要先编辑精简。

## 自定义系统提示词

模型配置的自定义系统提示词放在应用固定编码规则、启用能力说明之后，在本轮动态权限及对话之前，不覆盖固定权限边界。保存后用于之后的请求。稳定文本有利于保留相同前缀；修改提示词、工具集合或权限说明会改变相应前缀，实际缓存是否命中以及统计是否返回仍由服务决定。
