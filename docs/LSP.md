# 编辑器语言服务

编辑器使用 Sora 0.23.6 的实验性 LSP 模块，连接手机 Ubuntu 中的本地语言服务器。基础语法高亮仍可单独使用。初期范围为 Python 与 JavaScript／TypeScript，不代表 Kotlin、Java、C++ 或所有工程已具备语义支持。

## 使用

在环境工具包列表按需安装 **Python 语言服务** 或 **JavaScript / TypeScript 语言服务**。编辑相应文件时，底部状态入口显示检测、连接、诊断数量或失败；缺少服务时可从详情确认安装。安装需要联网，可能安装 Python venv、Node.js、npm 等依赖，不在打开文件时自动安装。

- Python：独立 venv 中的 Python LSP Server 及 Pyflakes，用于基础诊断和 Jedi 补全。
- JS / TS：独立 npm 前缀中的 TypeScript Language Server 与 TypeScript，支持 Node.js 18 及以上。
- 工具位置在 `/opt/zakocoder/lsp/`，不会向用户工程写入语言服务依赖。
- 通过编辑器现有补全弹窗和诊断标记查看结果。保存通知跟随成功的显式保存，语言服务不会替用户保存文件。

## 生命周期与边界

当前只有可见文档持有语言服务连接；切换文件、项目或离开编辑器会释放该连接，重新进入需要再次连接。因此大型工程的首次索引可能较慢。进程在应用所属 Ubuntu 中运行，二进制标准输入／输出传输 JSON-RPC，标准错误单独收集，取消时清理所属进程。

文档使用项目工作区路径，初始打开和内容变化发送编辑器的当前缓冲区，未保存内容可参与诊断及补全。服务可以读取同一运行环境可访问的工程文件；PRoot 不提供安全隔离，应仅为可信项目启用开发工具。

暂不提供完整重命名重构、符号搜索或导航界面，也不自动安装语言服务器插件。诊断准确性和第三方依赖解析取决于具体项目环境；独立 Python venv 不自动继承项目 venv 的所有包。失败后从状态详情重试，核对 Ubuntu 和工具包检测结果。

来源、版本及许可证见 [第三方材料](../THIRD_PARTY.md)。构建与设备验证结果应以对应 PR 的实际记录为准，安装入口存在不等于已在全部设备或工程上验证。
