# 界面与交互规范

## 目标与导航

界面首先说明当前项目、正在执行的操作和下一步，用真实代码、输出与结果呈现工作，不以演示数据模拟能力。采用 Kotlin + Compose 原生界面，系统字体显示信息，代码和终端使用等宽字体。

底部导航为项目库、环境、终端、助手和设置。切换页面不启动执行或改变项目。文件浏览、编辑器、模型配置和全屏终端使用独立层级；终端入口先显示卡片，点击才进入 PTY，返回保留会话。网页预览交给系统浏览器，不将网页原型作为应用页面。

## 视觉基础

| 语义 | 亮色 | 暗色 |
| --- | --- | --- |
| 背景 | `#F5F7FA` | `#0B0F14` |
| 表面 | `#FFFFFF` | `#151B23` |
| 正文 | `#0F172A` | `#E6EDF3` |
| 次要文字 | `#5B6B82` | `#9BA7B4` |
| 主操作／链接 | `#2563EB` | `#2F6FED`／`#4C8DFF` |
| 描边 | 使用主题语义色 | `#232B36` |
| 终端 | `#0D1117` | `#05080C` |

双主题保持相同尺寸和信息结构，暗色以描边和明度分层。主题切换不创建进程或清空输入。正文对比度目标至少 4.5:1，大字至少 3:1，仍需按实际组合复核。

沿用现有字阶：页面标题 24sp、弹层标题 19sp、卡片 16sp、区块 14sp、正文 13sp、辅助 12sp；终端默认 11sp 并尊重已存选择。新增页面使用现有主题和组件，不另起视觉体系。

页面水平留白通常 16–20dp，使用 4／8／12／16／20／24dp 间距。主要触控目标至少 48dp，图标可以更小，但相邻触区不得重叠。长路径可截断展示并提供必要来源，错误与关键说明允许换行；不能挤走关闭、保存或重试入口。

## 型号容量选择列表

模型上下文预设使用厂商分组：分组容器圆角 12dp，组内是整行可点击列表与缩进分隔线，不把多行信息套入默认胶囊按钮。行内距 12dp，最小高度 64dp，标题使用现有区块字阶，Model ID 和精确 Token 容量使用辅助字阶；空间不足自然换行，重要协议限制完整显示。夜间沿用主题表面、文字和描边色。容量选择只填入窗口，不以容量相同暗示多个模型同时被选中。

## 模型协议与常用服务选择

模型编辑页按连接、模型、生成参数、高级配置和连接测试组织。连接区只展示一个当前协议选择行：最小高度 56dp，12dp 内距与圆角，协议名与路径上下排列，末端使用进入箭头。点击后打开原生底部 Sheet，按 OpenAI 兼容、Anthropic 兼容和 Google 兼容分组选择四类协议；组容器圆角 12dp，内部采用平面整行、缩进分隔线及单选状态，不用四张大卡片或巨型胶囊挤占编辑表单。长内容自然换行，选择列表可滚动，关闭后保留表单草稿。

“常用服务”独立打开供应商列表。列表行最小高度 64dp、内距 12dp，依次显示服务名称、协议和官方基础地址。选中只填写地址与协议，保留模型、密钥和其他输入，不自动测试、保存或发送请求。更换服务来源时，在原配置存在凭据的情况下提示替换或清除密钥及私密请求头；提示不回显原值，也不暗示旧凭据可跨服务复用。供应商预设不代表所有型号和参数均已实测。

实际请求地址由协议路由统一生成，显示完整路径；Gemini 同时包含模型 ID、生成方法和流式查询参数。模型 ID 无效时说明需填写有效值，不显示误导性的可用地址。协议说明明确无需额外安装、服务必须支持所选接口，失败不会自动换协议。

参数限制紧跟协议控件，错误在同一区域明确提示，并阻止保存或测试无效配置。切换协议不会自动删除不兼容参数：Responses 禁用 seed 和两项 penalty；Anthropic 同样限制这三项、温度上限为 1，开启思考时禁止温度与 top_p 且显式输出上限须大于 1024；Gemini 暂不支持 max 推理强度。这三类协议在关闭思考时均要求推理强度设为“服务默认”。限制说明不能退化为统一的“连接失败”，服务实际参数能力仍由所选模型决定。

这组界面沿用现有亮暗主题及字阶，按 360dp、130% 字体检查真实模型编辑页、四协议选择、服务预设及任务运行时的只读状态；长地址允许换行，关闭和保存入口保持可达。截图验证与连接行为测试分别记录，不以截图宣称服务连接成功。

## 状态与恢复

列表至少明确加载、内容、空、失败。不可读取不等于空，缺失检查点不等于没有修改；切换项目、目录或轮次时清除旧的可点击结果，重试只读取当前身份，不静默退回根目录或执行工具。

失败提示说明当前无法确认的内容，并提供所属区域内的可执行恢复操作。保留草稿与选择，禁止用全局进度条挤压终端高度。普通成功提示可自动消失，错误保留到处理或关闭；取消与失败分开，停止过程区分“正在停止”和最终状态。

安装前展示准确包名，依赖安装前展示 cwd 和脚本。文件删除、终端关闭、丢弃未保存内容与恢复覆盖均说明影响范围并确认；不能只用一个无说明危险图标。容量展示应用实际使用量，使用十进制 MB／GB，不混入 RAM 或系统磁盘余额。

## 编码与 AI 页面

用户输入、助手 Markdown、模型公开计划和实际工具事件分层显示。上滑阅读停止自动跟随，提供回到最新；长正文预览、分页原文与日志截断明确标记范围。公开计划不充当执行结果，任务结束不自动显示测试通过。

审批显示工具、目标、参数、授权范围及副作用。代码审阅使用只读原文、修改后和差异页签，权限单改也要可识别；审批草案不提前修改文件。运行记录同时说明来源、任务轮次、退出状态及验证适用性。

输入框与配置草稿在页面往返及 Activity 重建中保留适当状态。键盘出现时保存、取消、发送和引用保持可达，表单可滚动；未保存编辑器内容与磁盘执行边界必须可见。模型密钥不回显、不放入可恢复页面状态。

终端卡片呈现等宽真实输出与文字状态，不放易误触的直接关闭按钮。详情菜单或切换面板提供确认关闭；辅助键条可横向滚动，方向键使用箭头及无障碍名称。

## AI 扩展的信息结构

助手页顶部将项目身份与历史、新会话、更多合并为一行，常驻“对话、变更”。请求、验收和数据发送说明放在更多菜单；上下文轮次及压缩统计保留在数据发送说明中。输入框下方固定模型选择、当前默认权限及扩展入口；长模型标识省略，不能挤走权限或扩展。模型选择弹层展示本机配置，提供切换、直接添加与管理入口，不自动请求服务。键盘出现时收起非必要摘要和导航，保留输入、发送与工具行。进入配置、扩展或请求页面不发送草稿，不清除当前会话引用。

“设置 → AI 扩展”使用 Skill、MCP 两个页签。Skill 上方明确项目及会话，搜索、详情与启停只作用于所选会话；新建与导入入口放在列表上方，保存至当前项目，默认不启用。MCP 卡片按名称与传输方式、目标、状态、次级操作分层，不将启用等同于在线。添加为列表下方唯一主按钮，JSON 导入在顶栏；连接测试、目录、编辑与删除为次级操作。表单正文全屏滚动，主保存按钮固定底部并避让键盘；连接方式使用选择行，参数、环境变量与请求头放在可展开的高级配置，收起不清除输入，机密字段默认遮蔽。返回不自动保存；保存后停用，启用和连接显式确认副作用。删除采用次级图标和二次确认。

扩展列表覆盖首次加载、空内容、读取失败、配置无效、连接中、失败及目录为空；只显示当前项目与服务的测试结果。无项目时可整理设备配置，不能启动项目连接。任务运行时管理页只读，不能在审批等待期间替换实际连接目标。

## 可访问性与文案

所有用户可见文案进入 Android 字符串资源，默认中文，术语统一；其他语言通过资源目录扩展。状态同时提供文字，不仅依赖颜色；可交互图标有名称，装饰图标避免重复朗读。

每个界面变更复核窄屏、亮暗主题、放大字体、长内容和键盘。TalkBack、焦点顺序、横屏与系统安全区需要实际验证，不能因采用 Material 组件就视为通过。截图只能证明对应状态，不能代替交互和执行验证。

设计不得把 PRoot 称为安全沙箱、把启动成功称为验证通过，或把未实现功能呈现为可用。范围和资源预算见[产品说明](PRODUCT.md)，贡献验证见[开发规范](DEVELOPMENT.md)。

## 品牌与常用操作

应用图标使用原创 Z 与代码光标矢量，主蓝 `#2563EB`、白色字形、浅蓝光标；桌面图标提供 adaptive 前景、背景与 monochrome，应用内品牌标识复用同一构形。系统通知使用平面矢量。设置使用标准八齿线性齿轮；所有功能图标沿用 24 单位网格、1.8 单位线宽与圆端点。

设置按助手、终端、环境与应用信息分组，标题和当前值上下排列，避免长值挤走名称。可点击普通行至少 48dp；终端辅助键每项至少 48×48dp，保留横向滚动。环境标题不放刷新图标，工具包区将“刷新”与“管理”并排；Zsh、Git、Python 显示推荐标识，安装仍由用户选择。环境维护使用文字入口。Git 文件列表独立滚动，选择计数、暂存和提交固定底部；选择文件不等于暂存，提交仍受状态完整性与任务锁约束。

## 对话细节与审阅入口

本轮设计沿用清晰、紧凑、可追溯三个关键词：把选择留在当前上下文，把状态放在对应轮次，把恢复与查看分开。模型搜索选择使用底部 Sheet，列表保留搜索、加载、失败重试、空列表与手填返回；表单草稿不因关闭选择而丢失。对话每轮末尾用 12sp 次要文字显示 ↑ 输入、↓ 输出、Σ 合计和 token/s，FlowRow 在窄屏自动换行；活动轮次放在输入区上方，不挤占模型/权限行。统计用 450ms 数值过渡，未返回的指标保持“—”。完成时间在用量下一行，沿用主题次要文字色。

文件变更按文件名/相对路径、所属轮次需求、绿色新增与红色删除数字分层，数字同时带正负号。检查点通过独立 Sheet 管理文件恢复及会话分叉，两者分别确认并说明文件/对话的影响。点击助手文件引用进入目录，在现有 primaryContainer 上高亮目标行并标记来源，不自动安装 APK 或执行文件。表格固定统一列宽并整表横滚，各行按最高单元格统一边框；不让每一行独立滚动。


## 流式回复、附件与连接测试

本轮沿用“清晰、紧凑、可追溯”：当前正在发生的过程可见，低频信息收进二级区域，截图与实际行为可对应。使用既有亮暗主题语义色和 4／8／12／16／24dp 间距，不增加独立配色。主要文字 13sp、辅助说明 12sp、面板标题 19sp；操作热区至少 48dp。

模型实际返回思考片段时，当前助手消息实时展开更新；开始正式正文或转入工具执行后自动收起，历史和已结束消息默认收起，用户仍可展开复核。不能等待整个请求结束才一次展示，也不能从最终回答推造思考文本。错误和停止保留已接收内容，不能冒充已完成。

附件面板顺序为标题、图片／文件／构建日志入口、已引用内容、当前项目文件。操作以图标、标题和短说明构成紧凑行；发送隐私和容量限制归在辅助说明，不能把多段说明挤在主要操作之间。文件列表保留加载、空、错误与重试，添加引用后有明确反馈。

模型连接测试就地显示真实阶段、已接收流片段与工具参数摘要；测试不执行模型返回的工具。运行中可取消，结束保留本次结果；修改草稿清除与新配置不匹配的旧结果。展示有界、脱敏的内容，不回显密钥、自定义请求头值或请求凭据。

## PR 界面证据归档

所有 UI 新增、修改和调整均在 PR 正文按改动位置附日间和夜间实际截图，对应提交固定后归档。流式、加载、确认、成功和失败等影响行为的状态，应提供相关关键帧；静态截图不能证明实时性，应另有流式交互验证。窄屏、字体放大、安全区与键盘按贡献规范复核。

仅本地环境无法取得夜间截图时，注明限制和已经执行的夜间适配验证；没有实际验证不得声明已适配。维护者先审核，修改后同步更新截图，不自动合并。

## MCP 错误反馈

失败区域沿用主题 errorContainer/onErrorContainer，12dp 圆角、12dp 横向内距，显示“操作未完成”、具体原因/建议与稳定代码。错误正文不使用三行省略，超过 160dp 可滚动；复制按钮触区至少 48dp，允许选择正文。导入失败保留表单，不自动关闭；配置、认证、地址限制和网络错误不能归并成同一条“操作失败”。详情只包含固定安全文案和状态码，不显示原始认证值或服务错误正文。


## 助手调试悬浮窗

悬浮窗服务于观看手机自动调试的用户，默认无需点开即可知道当前操作。调性为可扫读、可追溯、少打扰：默认横向监看卡显示助手调试、公开任务阶段及当前操作；点开才进入详情，不能把执行信息藏在只有标题的小按钮后。

监看卡宽 284dp，高 76dp 并随字体放大；左右 12dp 内距、图文间距 12dp，左侧 36dp 主题图标区，标题 13sp，当前操作 12sp。文字超过两行截断，完整信息在详情中；卡片整体可点击、可拖动，拖动不能误触展开。位置受系统安全区约束。

详情为独立窗口，竖屏宽不超过 400dp、两侧至少留 12dp，高不超过可用屏幕 72%／560dp；横屏接近可用全高，保留上下安全边距。依次为 56dp 标题栏、测试目标辅助行、真实进度、最近对话及固定底栏。顶栏右侧独立收起图标的触区为 48dp，拖动只在标题区；横屏收紧进度说明，保留实际对话阅读空间，禁止将正文挤成零高。

沿用主界面的亮暗主题：白／`#151B23` 表面，`#0F172A`／`#E6EDF3` 主文字，`#5B6B82`／`#9BA7B4` 辅助文字，`#2563EB`／`#4C8DFF` 主要操作。小卡圆角 12dp，详情圆角 16dp，1dp 语义描边。状态使用文字配合语义色：蓝色进行，绿色仅指该请求完成，红色失败；请求完成不等于整个测试通过。

最近对话区分用户与助手：角色辅助字阶、用户浅主色气泡靠右、助手正文靠左；正文使用现有 13sp／14sp 字阶，不将全部内容拼成日志段。正文可滚动，查看较早内容时不抢滚动，提供回到最新。底部返回对话是唯一主按钮，停止为次级危险操作，均保持至少 48dp 触区。

卡片在制品校验阶段保持可见。读屏、截图、触控及启动系统界面前安全让出屏幕，恢复显示真实动作结果；保持原展开状态、位置、阅读位置与是否跟随最新内容。不能显示原始 JSON、虚构进度百分比或把任何成功统一称为测试通过。停止、取消、切换目标后旧窗口不得复活。日夜、横屏、130% 字体和暂隐恢复均需真实设备证据，并由独立视觉审查核对层级与可读性。


## 对话内提问

面向手机上与助手确认开发方向的用户，采用清楚、就地、可恢复的结构：问题在原工具位置展示，顺序为助手提问／等待状态、问题正文、单选选项、自定义回答、暂停说明及唯一主操作“提交回答并继续”。不另外跳页，不将回答当成权限审批。

复用亮暗主题表面与 1dp 描边，卡片圆角 12dp、内距 16dp、区块间距 12dp；选项圆角 8dp、最小触区 48dp，选中用 primaryContainer 和单选标记共同表达。问题正文沿用正文语义样式，辅助状态与说明使用次要文字。选项文字完整换行，问题及已保存回答可选择复制。自定义输入始终可见，最多 4096 字符，2–6 行内部滚动；选择选项清空自定义内容，输入自定义回答取消原选择。

主操作为 48dp 高全宽按钮，未填写时禁用。已回答变为只读回执；仅回答已保存且任务尚待续接时提供“继续任务”。取消保留问题／回答并标记已取消，不能再次提交。普通消息输入在等待期间提示先回答或停止；原停止入口可取消任务。键盘沿用助手页面的 IME 安全区及可滚动对话，日夜使用同一结构；截图和交互验证分开记录。
