# 界面与交互规范

## 目标与导航

界面首先说明当前项目、正在执行的操作和下一步，用真实代码、输出与结果呈现工作，不以演示数据模拟能力。采用 Kotlin + Compose 原生界面，系统字体显示信息，代码和终端使用等宽字体。

应用默认进入助手对话。左上角侧栏依次提供助手、对话记录、工作区、环境、终端和设置；不常驻底部导航。工作区承载原项目库的创建、导入、绑定、文件与项目命令；对话记录使用当前工作区已有会话，切换工作区不会混用历史。切换页面不启动执行或改变项目。文件浏览、编辑器、模型配置和全屏终端使用独立层级；终端入口先显示卡片，点击才进入 PTY，返回保留会话。网页预览交给系统浏览器，不将网页原型作为应用页面。

## 视觉基础

| 语义 | 亮色 | 暗色 |
| --- | --- | --- |
| 背景 | `#F7F7F7` | `#000000` |
| 表面 | `#FFFFFF` | `#242424` |
| 正文 | `#000000` | `#F2F2F2` |
| 次要文字 | `#606060` | `#BDBDBD` |
| 主操作／链接 | `#2563EB` | `#2F6FED`／`#4C8DFF` |
| 卡片描边 | `#E0E0E0` | `#393939` |
| 分隔线 | `#E0E0E0` | `#393939` |
| 终端 | `#0D1117` | `#05080C` |

双主题保持相同尺寸和信息结构，暗色以表面明度和留白分层。主题切换不创建进程或清空输入。正文对比度目标至少 4.5:1，大字至少 3:1，仍需按实际组合复核。

全局字阶集中在 `ui/theme/Type.kt`：页面标题 20sp／28sp、弹层与分组标题 16sp／24sp、卡片与普通界面正文 14sp／20sp、辅助 12sp／17sp、标签 11sp／15sp。标题使用常规或 Medium 字重，长说明不加粗。聊天正文仍为 12sp／18sp，终端默认 11sp 并尊重已存选择。全局 Typography 只在主题层声明，普通表单不继承长文行距。新增页面使用现有主题和组件，不另起视觉体系。

普通卡片使用 12dp 圆角，不加装饰边框或投影；分层依靠背景明度和留白，描边仅用于选中、危险或错误等必要状态。可编辑控件的边框保留更高对比度，不能把输入框焦点、选中态一起淡化。连续文件列表只画行间分隔线，避免逐行边框叠加。Material 默认圆角集中在 `ui/theme/Radius.kt`，默认控件按 8／12／16／24dp 档位取值，底部 Sheet 顶角显式使用 24dp。

页面水平留白通常 16–20dp，使用 4／8／12／16／20／24dp 间距。主要触控目标至少 48dp，图标可以更小，但相邻触区不得重叠。长路径可截断展示并提供必要来源，错误与关键说明允许换行；不能挤走关闭、保存或重试入口。

## 型号容量选择列表

模型上下文预设使用厂商分组：分组容器圆角 12dp，组内是整行可点击列表与缩进分隔线，不把多行信息套入默认胶囊按钮。行内距 12dp，最小高度 64dp，标题使用现有区块字阶，Model ID 和精确 Token 容量使用辅助字阶；空间不足自然换行，重要协议限制完整显示。夜间沿用主题表面、文字和描边色。容量选择只填入窗口，不以容量相同暗示多个模型同时被选中。

## 模型协议与常用服务选择

模型编辑页按连接、模型、生成参数、高级配置和连接测试组织。连接区只展示一个当前协议选择行：最小高度 56dp，12dp 内距与圆角，协议名与路径上下排列，末端使用进入箭头。点击后打开原生底部 Sheet，按 OpenAI 兼容、Anthropic 兼容和 Google 兼容分组选择四类协议；组容器圆角 12dp，内部采用平面整行、缩进分隔线及单选状态，不用四张大卡片或巨型胶囊挤占编辑表单。长内容自然换行，选择列表可滚动，关闭后保留表单草稿。

“常用服务”独立打开供应商列表。列表行最小高度 64dp、内距 12dp，依次显示服务名称、协议和官方基础地址。选中只填写地址与协议，保留模型、密钥和其他输入，不自动测试、保存或发送请求。更换服务来源时，在原配置存在凭据的情况下提示替换或清除密钥及私密请求头；提示不回显原值，也不暗示旧凭据可跨服务复用。供应商预设不代表所有型号和参数均已实测。

实际请求地址由协议路由统一生成，显示完整路径；Gemini 同时包含模型 ID、生成方法和流式查询参数。模型 ID 无效时说明需填写有效值，不显示误导性的可用地址。协议说明明确无需额外安装、服务必须支持所选接口，失败不会自动换协议。

参数限制紧跟协议控件，错误在同一区域明确提示，并阻止保存或测试无效配置。切换协议不会自动删除不兼容参数：Responses 禁用 seed 和两项 penalty；Anthropic 同样限制这三项、温度上限为 1，开启思考时禁止温度与 top_p 且显式输出上限须大于 1024；Gemini 暂不支持 max 推理强度。这三类协议在关闭思考时均要求推理强度设为“服务默认”。限制说明不能退化为统一的“连接失败”，服务实际参数能力仍由所选模型决定。

这组界面沿用现有亮暗主题及字阶，按 360dp、130% 字体检查真实模型编辑页、四协议选择、服务预设及任务运行时的只读状态；长地址允许换行，关闭和保存入口保持可达。截图验证与连接行为测试分别记录，不以截图宣称服务连接成功。

## 状态与恢复

列表至少明确加载、内容、空、失败。不可读取不等于空，缺失检查点不等于没有修改；切换项目、目录或轮次时清除旧的可点击结果，重试只读取当前身份，不静默退回根目录或执行工具。

失败提示说明当前无法确认的内容，并提供所属区域内的可执行恢复操作。保留草稿与选择，禁止用全局进度条挤压终端高度。普通成功提示可自动消失，错误保留到处理或关闭；取消与失败分开，停止过程区分“正在停止”和最终状态。

安装前展示准确包名，依赖安装前展示 cwd 和脚本。文件删除、终端关闭、丢弃未保存内容与恢复覆盖均说明影响范围并确认；不能只用一个无说明危险图标。容量展示应用实际使用量，使用十进制 MB／GB，不混入 RAM 或系统磁盘余额。

## 编码与 AI 页面

用户输入、助手 Markdown、模型公开计划和实际工具事件分层显示。上滑阅读停止自动跟随，提供回到最新；长正文预览、分页原文与日志截断明确标记范围。公开计划不充当执行结果，任务结束不自动显示测试通过。

审批显示工具、目标、参数、授权范围及副作用。代码审阅使用只读原文、修改后和差异页签，权限单改也要可识别；审批草案不提前修改文件。运行记录同时说明来源、任务轮次、退出状态及验证适用性。

输入框与配置草稿在页面往返及 Activity 重建中保留适当状态。键盘出现时保存、取消、发送和引用保持可达，表单可滚动；未保存编辑器内容与磁盘执行边界必须可见。模型密钥不回显、不放入可恢复页面状态。

终端卡片呈现等宽真实输出与文字状态，不放易误触的直接关闭按钮。详情菜单或切换面板提供确认关闭；辅助键条可横向滚动，方向键使用箭头及无障碍名称。

## AI 扩展的信息结构

助手页顶部将会话、项目身份与历史、新会话、更多合并为一行，不再常驻“对话、变更”页签或展开计划卡。运行中顶栏下显示 2dp 活动线，不将其解释为实际完成比例。当前正在执行的轮次末尾提供过程摘要与计划详情入口；请求、验收、全部轮次变更、扩展和数据发送说明放在更多菜单，检查点保留独立入口。上下文轮次及压缩统计保留在数据发送说明中。连续成功工具按活动汇总，保留读取、写入和命令等实际类型及次数；完全空白的工具响应消息不切断汇总，正文与思考内容仍保持顺序。同轮准备信息可跨过无正文的思考消息收入工具详情。错误、运行中工具与审批独立保留。只有思考而没有正文的消息，其更多操作放在思考标题同行，避免多出空操作行。输入、附件、模型选择、当前默认权限与发送／停止整合为同一个 26dp 圆角容器；发送视觉为 36dp 圆形，保留 48dp 热区；权限位于模型左侧，模型名与思考／上下文摘要在同一轻胶囊内单行显示，长标识省略，不能挤走权限或发送。模型选择弹层展示本机配置，提供切换、直接添加与管理入口，不自动请求服务。回复的复制、更多与紧凑变更入口同排显示，完整文件列表和差异放入审阅页；有限、未封存或读取失败不可冒充完整变更。参数接收阶段仅显示单行工具名称与生成状态，不在主流展开参数 JSON。回到最新放在输入区上方的独立行，不能覆盖正文。键盘出现时收起非必要摘要，保留输入、发送与工具行。进入配置、扩展或请求页面不发送草稿，不清除当前会话引用。

“设置 → AI 扩展”使用 Skill、MCP 两个页签。Skill 与 MCP 为应用全局配置，无工作区也可浏览、添加和导入。Skill 开关跨工作区共享，每次任务开始时固定快照；新建与导入保存至应用私有库，默认不启用。工作区只组织源码与对话，不拥有扩展配置。MCP 卡片按名称与传输方式、目标、状态、次级操作分层，不将启用等同于在线。添加为列表下方唯一主按钮，JSON 导入在顶栏；连接测试、目录、编辑与删除为次级操作。表单正文全屏滚动，主保存按钮固定底部并避让键盘；连接方式使用选择行，请求头放在可展开的高级配置，收起不清除输入，机密字段默认遮蔽。返回不自动保存；保存后停用，启用和连接显式确认副作用。删除采用次级图标和二次确认。

扩展列表覆盖首次加载、空内容、读取失败、配置无效、连接中、失败及目录为空；只显示当前服务的测试结果。MCP 仅提供 Streamable HTTP 与 SSE，支持域名、IP、localhost 和 127.0.0.1；无工作区也可测试网络连接，不提供 stdio 进程模式。任务运行时管理页只读，不能在审批等待期间替换实际连接目标。

## 可访问性与文案

所有用户可见文案进入 Android 字符串资源，默认中文，术语统一；其他语言通过资源目录扩展。状态同时提供文字，不仅依赖颜色；可交互图标有名称，装饰图标避免重复朗读。

后续界面变更以目标真机尺寸、默认字号复核亮暗主题、长内容和键盘；模拟器记录分辨率与密度，130% 字体不再作为必测项。TalkBack、焦点顺序、横屏与系统安全区需要实际验证，不能因采用 Material 组件就视为通过。截图只能证明对应状态，不能代替交互和执行验证。

设计不得把 PRoot 称为安全沙箱、把启动成功称为验证通过，或把未实现功能呈现为可用。范围和资源预算见[产品说明](PRODUCT.md)，贡献验证见[开发规范](DEVELOPMENT.md)。

## 品牌与常用操作

应用图标使用原创 Z 与代码光标矢量，主蓝 `#2563EB`、白色字形、浅蓝光标；桌面图标提供 adaptive 前景、背景与 monochrome，应用内品牌标识复用同一构形。系统通知使用平面矢量。设置使用标准八齿线性齿轮；所有功能图标沿用 24 单位网格、1.8 单位线宽与圆端点。

设置按助手、终端、环境与应用信息分组，标题和当前值上下排列，避免长值挤走名称。可点击普通行至少 48dp；终端辅助键每项至少 48×48dp，保留横向滚动。环境标题不放刷新图标，工具包区将“刷新”与“管理”并排；Zsh、Git、Python 显示推荐标识，安装仍由用户选择。环境维护使用文字入口。Git 文件列表独立滚动，选择计数、暂存和提交固定底部；选择文件不等于暂存，提交仍受状态完整性与任务锁约束。

## 对话细节与审阅入口

本轮设计沿用清晰、紧凑、可追溯三个关键词：把选择留在当前上下文，把状态放在对应轮次，把恢复与查看分开。模型搜索选择使用底部 Sheet，列表保留搜索、加载、失败重试、空列表与手填返回；表单草稿不因关闭选择而丢失。对话每轮末尾用 12sp 次要文字显示 ↑ 输入、↓ 输出、Σ 合计和 token/s，FlowRow 在窄屏自动换行；活动轮次不在输入区上方常驻显示 Token，不挤占模型／权限行。统计用 450ms 数值过渡，未返回的指标保持“—”。完成时间在用量下一行，沿用主题次要文字色。

文件变更在所属轮次最终回复的复制／更多操作旁提供紧凑可点摘要，展示文件数、绿色 +N、红色 −N 与必要的范围状态；详细审阅页保留增删比例条，数字与比例条必须取自同一份真实差异。点击打开底部抽屉，保留所属轮次，文件按增删总量排序；点击文件行原地展开只读 diff，短差异按内容自适应高度，红绿整行背景；完整编辑器审阅保留二级入口。已封存记录以对应轮次检查点为准，运行中观察记录必须带有当前轮次归属；没有修改的新轮次不能继承旧轮次统计。历史切换、加载、失败、缺失与真实空变更仍分别表示。文件名／相对路径、所属轮次需求与数字分层；撤销保留既有确认和覆盖检查。检查点通过独立 Sheet 管理文件恢复及会话分叉，两者分别确认并说明文件/对话的影响。点击助手文件引用进入目录，在现有 primaryContainer 上高亮目标行并标记来源，不自动安装 APK 或执行文件。表格按各列内容分配64–200dp基础宽度，同列各行保持一致；退出码等短内容不占据与长结果同样的宽度。整表横滚，超宽时显示滑动提示，各行按最高单元格统一边框，不让每一行独立滚动。短代码块将语言、正文与复制放在紧凑容器，复制仍保留48dp热区。


## 流式回复、附件与连接测试

本轮沿用“清晰、紧凑、可追溯”：当前正在发生的过程可见，低频信息收进二级区域，截图与实际行为可对应。使用既有亮暗主题语义色和 4／8／12／16／24dp 间距，不增加独立配色。主要文字 13sp、辅助说明 12sp、面板标题 19sp；操作热区至少 48dp。

模型实际返回思考片段时，当前助手消息实时展开更新；开始正式正文或转入工具执行后自动收起，历史和已结束消息默认收起，用户仍可展开复核。不能等待整个请求结束才一次展示，也不能从最终回答推造思考文本。错误和停止保留已接收内容，不能冒充已完成。

附件面板顺序为标题、图片／文件／构建日志入口、已引用内容、当前项目文件。操作以图标、标题和短说明构成紧凑行；发送隐私和容量限制归在辅助说明，不能把多段说明挤在主要操作之间。文件列表保留加载、空、错误与重试，添加引用后有明确反馈。

模型连接测试就地显示真实阶段、已接收流片段与工具参数摘要；测试不执行模型返回的工具。运行中可取消，结束保留本次结果；修改草稿清除与新配置不匹配的旧结果。展示有界、脱敏的内容，不回显密钥、自定义请求头值或请求凭据。

## PR 界面证据归档

所有 UI 新增、修改和调整均在 PR 正文按改动位置附日间和夜间实际截图，通过 PR 附件关联对应提交，不将验收图集提交到源码仓库；长期产品图片与例外规则见[贡献指南](../CONTRIBUTING.md#截图与媒体文件)。流式、加载、确认、成功和失败等影响行为的状态，应提供相关关键帧；静态截图不能证明实时性，应另有流式交互验证。窄屏、字体放大、安全区与键盘按贡献规范复核。

仅本地环境无法取得夜间截图时，注明限制和已经执行的夜间适配验证；没有实际验证不得声明已适配。维护者先审核，修改后同步更新截图，不自动合并。

## MCP 错误反馈

失败区域沿用主题 errorContainer/onErrorContainer，12dp 圆角、12dp 横向内距，显示“操作未完成”、具体原因/建议与稳定代码。错误正文不使用三行省略，超过 160dp 可滚动；复制按钮触区至少 48dp，允许选择正文。导入失败保留表单，不自动关闭；配置、认证、地址限制和网络错误不能归并成同一条“操作失败”。详情只包含固定安全文案和状态码，不显示原始认证值或服务错误正文。


## 助手调试悬浮窗

悬浮窗服务于观看手机自动调试的用户，默认无需点开即可知道当前操作。调性为可扫读、可追溯、少打扰：默认横向监看卡显示助手调试、公开任务阶段及当前操作；点开才进入详情，不能把执行信息藏在只有标题的小按钮后。

监看卡宽 284dp，高 76dp 并随字体放大；左右 12dp 内距、图文间距 12dp，左侧 36dp 主题图标区，标题 13sp，当前操作 12sp。文字超过两行截断，完整信息在详情中；卡片整体可点击、可拖动，拖动不能误触展开。位置受系统安全区约束。

详情为独立窗口，竖屏宽不超过 400dp、两侧至少留 12dp，高不超过可用屏幕 72%／560dp；横屏接近可用全高，保留上下安全边距。依次为 56dp 标题栏、测试目标辅助行、真实进度、最近对话及固定底栏。顶栏右侧独立收起图标的触区为 48dp，拖动只在标题区；横屏收紧进度说明，保留实际对话阅读空间，禁止将正文挤成零高。

沿用主界面的亮暗主题：白／`#151B23` 表面，`#0F172A`／`#E6EDF3` 主文字，`#5B6B82`／`#9BA7B4` 辅助文字，`#2563EB`／`#4C8DFF` 主要操作。小卡圆角 12dp，详情圆角 16dp，1dp 语义描边。状态使用文字配合语义色：蓝色进行，绿色仅指该请求完成，红色失败；请求完成不等于整个测试通过。

最近对话区分用户与助手：角色辅助字阶、用户浅主色气泡靠右、助手正文靠左；正文使用现有 13sp／14sp 字阶，不将全部内容拼成日志段。正文可滚动，查看较早内容时不抢滚动，提供回到最新。底部返回对话是唯一主按钮，停止为次级危险操作，均保持至少 48dp 触区。

卡片在制品校验阶段保持可见。读屏、截图、触控及启动系统界面前安全让出屏幕，恢复显示真实动作结果；保持原展开状态、位置、阅读位置与是否跟随最新内容。不能显示原始 JSON、虚构进度百分比或把任何成功统一称为测试通过。停止、取消、切换目标后旧窗口不得复活。日夜、横屏、130% 字体和暂隐恢复均需真实设备证据，并由独立视觉审查核对层级与可读性。


## 对话内提问

面向手机上与助手确认开发方向的用户，采用清楚、就地、可恢复的结构：问题在原工具位置展示，顺序为助手提问／等待状态、问题正文、单选选项、自定义回答、暂停说明及唯一主操作“提交回答并继续”。不另外跳页，不将回答当成权限审批。

复用亮暗主题表面与 1dp 描边，卡片圆角 12dp、内距 12dp、区块间距 8dp；选项圆角 8dp、最小触区 48dp，选中用 primaryContainer 和单选标记共同表达。问题正文沿用正文语义样式，辅助状态与说明使用次要文字。选项文字完整换行，问题及已保存回答可选择复制。自定义回答通过轻量入口按需展开，恢复非空草稿时保持展开，最多 4096 字符，1–4 行内部滚动；选择选项清空自定义内容，输入自定义回答取消原选择。

主操作为 48dp 高全宽按钮，未填写时禁用。已回答默认收起为一行只读回执，可展开查看原问题及复制完整答案；仅回答已保存且任务尚待续接时提供“继续任务”。取消保留问题／回答并标记已取消，不能再次提交。普通消息输入在等待期间提示先回答或停止；原停止入口可取消任务。键盘沿用助手页面的 IME 安全区及可滚动对话，日夜使用同一结构；截图和交互验证分开记录。

## 用户说明与技术详情

常驻文案先说明用途、当前状态与下一步；实现字段、统计口径和较长兼容限制放入同一区域的可展开说明。默认收起的说明使用至少 48dp 触区，并提供展开状态与操作标签。危险操作的后果、实际授权范围和错误恢复方式仍在操作附近显示，不以折叠说明替代必要确认。

版本号取实际安装包信息，不硬编码开发版本。关于页提供简短产品介绍、开源组件说明和可读取的原始许可全文；简化说明不得删除来源和许可证义务。

## 安装和下载日志

环境安装及工具包安装使用独立终端式日志区：等宽字、固定视口、真实增量输出，默认跟随底部。用户向历史滚动时暂停跟随，点击回到最新恢复；跟随控制行保持固定高度，不能在暂停时推动正文。新操作自动展开并定位一次，后续输出只滚动日志内部，不反复拉动整个页面。日志截取明确标记，失败原文与取消、重试入口保留；显示日志不创建新的 Shell 或执行日志内容。

聊天正文使用12sp／18sp行高，用户消息与助手正文保持一致。实时工具参数以单行“动作＋最新内容”呈现，换行后显示最新非空行，默认折叠，点击展开有界参数详情；长参数保留开头和明确标注的最新片段，不影响真实执行参数。最终消息操作行为变更摘要靠左、复制与更多靠右，两行用量与耗时统计靠左对齐。会话标题与项目名统一左对齐；任务描述输入框及占位文字使用12sp／18sp行高。

请求与接收阶段的状态文字使用从左向右的灰阶明暗扫光，单次循环1600ms；文字位置、字宽与辅助功能标签保持稳定，仅更新字形绘制，退出对应活动阶段即停止。输入区权限文字10sp、盾牌14dp、模型名称11sp、思考及上下文10sp，保留至少48dp点击区域。

流式正文增长时停用当前活动轮次的位置补间，不在自动跟随过程中临时插入“回到最新”行；用户离开底部后才提供返回入口。当前回复的复制、更多与变更操作在请求结束且显示文字追齐后出现，避免随逐字输出不断移动；历史消息操作不受影响。


## 首次使用配置

首次新安装进入七步配置：主要用途、Ubuntu 环境、AI 服务、默认 Skill、开发工具包、权限、就绪。按用途预选建议，用户可以增减；推荐不等于安装。沿用系统字体、主题蓝和中性色，页面内容左对齐，底部固定继续操作并避让系统栏与键盘。步骤和选择保存在本机，重启恢复；安装日志显示真实结果并可取消。

配置均可稍后完成；Ubuntu 与工具包只在明确点击安装后执行，SDK 许可仍单独确认。清华／官方选项为 Ubuntu 内 APT 软件源，不改变首次 rootfs 下载来源。Full 的本地镜像也须经环境确认，跳过后不能以完成引导为由静默安装。AI 服务复用已有加密配置和连接测试，Skill 选择与全局管理共用同一配置，修改在下次任务生效；正在执行或等待回答的任务保留原快照。系统授权集中列出用途与状态，逐项主动授予，拒绝不阻止进入；项目级工具审批仍在选定工作区后配置。

已有项目、环境或模型配置的安装直接进入助手，不强制重新初始化。设置提供重新进入配置的入口，保留现有选择与数据。顶栏和底部操作位置固定；步骤内容按前进、返回方向进行短距离滑动与淡入淡出，各步骤使用独立滚动区域。选项以底色过渡反馈选择，工具包安装入口固定在底部。最后使用短暂、可取消的缩放淡出进入过场，不添加固定等待，不伪造安装完成或联网进度；动画遵循系统动画时长设置。 冷启动、重新打开初始化配置和配置完成均通过统一进场层衔接：必要本地状态就绪后，在遮罩下完成目标首次布局与滚动恢复，再淡入并轻微缩放进入。助手在进入前恢复会话并在后台预热最近两条回复（每条最多64,000字符）的 Markdown 缓存；不等待网络检测、工具检测或软件下载安装。Markdown 预热失败降级回正常渲染，不阻断启动；取消仍正常传播。冷启动只保留一次完整进场；同一加载指示器持续到目标首次布局与揭示过渡完成，不在启动状态切换时重建，也不在数据刚就绪时提前移除。已就绪页面的普通进场不额外显示加载圈，已有页面进入后不因后台刷新重新显示启动层。主要导航及引导内的配置详情提供短过渡，动画期间阻止点击穿透；不以固定延时伪装加载。

## Miuix 原生组件迁移

Miuix 0.9.4 提供主应用主题、控件反馈、设置分组及公共底部面板。公共主题同时向保留的 Material 复杂布局提供同源颜色，避免编辑器、终端及渐进迁移页面出现两套明暗表面。聊天沿用紧凑字阶，系统权限、工具审批及真实进程状态不因组件替换改变。普通卡片不增加投影。单选、多选与开关均保留原有回调、禁用状态及至少48dp独立操作区域；表单标签绑定真实编辑节点，密码遮蔽和错误校验由原业务继续控制。

侧栏滑动进度与主页位移、轻微缩放、圆角同步；终端及编辑器仍遵循既有手势禁用约束。不可直接关闭的工具审批独立消费返回手势，避免预测返回把待审内容移出屏幕；只有明确的审批操作改变任务状态。公共面板先执行关闭动效再通知所属页面移除，保留返回、遮罩关闭、键盘避让及内容滚动。迁移验收覆盖日夜模式、返回与取消、长文本、窄屏和实际设备上的进退场，不将编译成功当成视觉验收。

全屏详情的返回预览应露出实际父页面，保留滚动位置和草稿；被覆盖的父页不得接收输入或完成后台导航。全屏窗口不使用模态灰幕，普通确认和审批继续保留遮罩。独立窗口使用自己的返回事件源；取消回弹及回弹中再次滑动保持位置连续。保存期间应消费返回，不能把用户退出应用。公共按钮、点击卡片和设置行保留按压反馈，接受点击后提供一次短触感，尊重系统触感设置，不在滑动每帧或取消按压时震动。

普通工作卡片、设置分组和状态摘要统一使用 `WorkbenchCard`：真实 Miuix 卡片、12dp 圆角、零常规投影，内距采用12或16dp。普通分组不叠加装饰描边；选中、危险和错误状态保留必要的语义反馈。专用终端画布、代码差异、消息气泡、徽章及根页面背景不机械改为卡片。调试悬浮窗仅保留1dp轻投影，以区分覆盖的其他应用。组件替换须保留单选／多选角色、禁用条件、长按、日志跟随与原有操作归属。

助手输入卡片在已消费系统栏和键盘 Insets 的容器内，另保留4dp底部视觉留白，不重复叠加导航栏高度。含描述的 Skill 列表项上下各留8dp，分隔线从正文起点缩进48dp；列表项之间的间距不能代替同一条目内描述与分隔线的距离。验收需实际打开详情、切换标签、弹出和收起键盘，并核对日夜模式，不能仅以入口截图代替内部布局检查。

## 工作区与对话层级

侧栏以对话为主：顶部新增对话，中部按工作区分组的可展开对话列表，底部将设置、环境、终端、Skill、MCP、能力包横向等分为一排，上图标、下文字，保持固定。仅中间列表滚动，管理工作区保留独立入口；点击对话直接进入助手，加载失败保留重试，不修改存储中的选中会话。工作区管理仍可进入完整对话列表，再选择已有对话或新增对话。工作区内部返回依次回到所属工作区的对话列表、全部工作区；聊天标题指向工作区内列表，助手首页系统返回交由 Android 处理。文件浏览、终端为工作区工具入口，不再将点击工作区等同于打开文件树。

添加工作区先选模式：Work 在应用私有目录创建、导入副本或克隆；本地通过图形目录选择绑定原目录，直接修改原文件。两种模式均沿用稳定工作区 ID 和原有存储位置，不自动迁移源码，也不自动转换已有工作区模式。同一工作区的多条对话共用源码，不宣称每条对话有独立容器或 Git 工作树。切换模式需要显式添加另一个工作区。

工作区内的会话列表仅展示属于该工作区的已加载历史。跨工作区切换需等待目录选中和会话身份一致，加载或保存失败保留错误和重试，不显示上一工作区的旧列表。活动任务期间只允许查看当前工作区，不切换其他工作区或新增、删除会话。移除 Work 工作区会删除其应用内源码，本地工作区只解除绑定；确认提示继续区分两者。


终端管理沿用工作区分组结构：顶部标题与新建操作，辅助行显示真实会话总数和运行数；按所属工作区列出会话，当前工作区优先。会话卡片使用统一零投影卡片，标题、状态点和进入箭头同一行，下面保留深色等宽的真实输出预览。关闭会话仍在终端内操作，不在卡片增加危险快捷动作。空状态根据环境和工作区情况提供唯一下一步，新建面板使用工作区语义，工作区列表独立滚动，创建按钮固定在底部；不为美观自动创建进程或填充演示输出。

侧栏 Skill、MCP 和能力包进入各自独立页面，不经设置或扩展标签页；系统返回和页内返回恢复进入前的页面。快捷图标使用同一线性矢量体系：手册表示 Skill、连接插头表示 MCP、积木表示能力包，来源与许可证按第三方材料保留。

助手更多菜单保留会话审阅相关入口，模型和工具权限沿用输入区入口，Skill、MCP、能力包沿用侧栏入口，避免重复。进入工作区后，从右上角选择构建、运行或测试，先打开既有命令管理页并优先展示相应命令，不直接启动执行。数据说明和命令确认内容由公共弹窗统一限高滚动，调用方不再嵌套无界纵向滚动。

常用页面支持系统预测性返回进度：手势期间仅改变当前页面位移、缩放和圆角，提交后才改变导航状态，取消则回弹，不提前执行文件或任务操作。系统未提供连续手势进度时沿用返回完成行为。底部快捷切换与返回确认使用系统轻触反馈，尊重设备触感设置，不在每帧、滚动或取消时反复震动；底部面板及审批沿用自身关闭和阻止返回规则。

预测返回预览实际父页，横移随手势进度最多为页面宽度72%，缩放最多1.8%，圆角随同一进度变化。取消用无反复弹跳的弹簧收敛；同侧再次接手继承未完成的位移，避免先闪回原位。 拖动透明度最多降低12%，保持文字可读；确认返回后从当前位置执行180ms位移与淡出，完全退场并绘制结束帧后才移除页面。脏稿或忙碌状态先恢复当前页再请求确认，不先退场；退出期间阻止重复返回和页面操作。引导步骤返回不叠加第二次内容过渡。实际系统手势支持与视觉验收分别记录，不将事件注入测试当作系统效果证明。

返回预览必须显示实际目标界面：独立配置页叠在仍保留的原页面之上；设置、环境、终端库下面保留唯一的助手界面，终端详情下面显示实际会话列表。工作区内的文件等详情返回时预览实际工作区父页；助手首页不预置工作区返回层。预览层屏蔽触摸与可访问性焦点，不能提前切换会话、启动工具或执行导航；取消保留原页面。不能用纯色占位或演示截图替代目标界面。

返回过渡按页面身份保存独立状态，目标页面的首帧不得继承来源页面的透明度、位移或退出锁定。离开设置时关闭其代理详情状态，退出中的旧设置回调不得在消息页或工作区打开代理。从设置连续返回应依次到助手、桌面，不跳入未选择的工作区或设置详情。

助手是桌面启动的根页面，根页面返回交由 Android 返回桌面，不创建工作区或代理页。工作区通过标题或侧栏显式进入；设置等详情返回进入前保留的页面。

侧栏工作区保留原有字号、图标颜色和会话缩进，分组背景与侧栏一致，仅在相邻工作区之间绘制分割线，最后一组不画；细分割线使用 0.5dp、50% 不透明度的 outlineVariant 主题色，松手后仍须可辨，不能依赖按压反馈；不增加彩色标题块、描边或竖向引导线。侧栏设置、环境、终端及独立扩展入口在实际来源页之上打开，详情背景覆盖包含系统栏区域的整个屏幕，仅内容应用安全区内边距，并盖住仍保持打开的原侧栏；Skill、MCP、能力包的背景随详情层一起移动，外层不保留固定纯色底板，返回仅移除详情层，保留分组展开和滚动位置，不关闭后再次打开侧栏；从工作区进入不得退到助手。助手根页返回桌面的规则保持不变。

助手展示以正文为主：正文保留12sp／18sp，思考采用轻底色、11sp／17sp辅助文字，工具摘要使用14dp类型图标与11sp动作／目标，状态10sp；展开参数及输出缩进22dp，成功过程汇总的子项缩进20dp。任务计划独立保留编号、当前状态和进度，活动项突出，其余采用辅助色。错误与待审批仍就地显露，不能被过程折叠隐藏。

流式正文以完整文本排版，尾部节点用连续浮点位置在200ms内横向显露；末端字形同时裁切和渐显，已显示文字保持稳定，不叠加截取字符串的打字计时。只为末端字形创建局部透明层。运行中的工具组保留同一行身份，成功不会立即替换为另一组件；子项按操作身份只做一次800ms渐显，整组在任务结束后统一收起，展开状态尊重用户选择。待审批、错误和未知工具保持独立显露。历史静态内容立即显示，系统关闭动画时直接显示；展示动画不延迟数据保存、审批或执行。

助手输出末尾固定保留两行正文行高的空白，运行与完成状态保持一致。新增换行和工具区域增长按实际列表布局逐帧跟随，不因每个流式片段重启滚动，也不逐行瞬移到底部；空闲时等待布局变化，不持续请求动画帧。用户上滑即暂停跟随，回到底部或点击“最新消息”后恢复；首次打开已有会话直接定位末尾。
