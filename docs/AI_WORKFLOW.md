# AI 编码工作流

ZakoCoder 按项目组织需求、会话、文件操作、终端和验证。模型回复、执行计划和“完成”声明不是验证结果；实际修改、授权和命令退出事实分别展示。

## 模型与任务

在设置或 AI 页管理命名模型配置，支持自定义 HTTPS Chat Completions 兼容服务、手填模型及主动获取模型列表。服务需支持 SSE `tool_calls`；未接入 Responses 或 Anthropic 原生协议。没有预置服务、模型或密钥。密钥由设备 Keystore 加密，不回显或随项目导出；跨服务源需重新填写或清除，活动任务期间不能切换配置。

流式工具测试使用当前表单输入，不执行项目工具，可能产生服务费用，成功不自动保存。模型收到的项目文本会发送给配置的服务。应用没有启动时模型请求或遥测。

当前只允许一个活动任务。页面离开不停止任务，可显式停止；重启不恢复执行或重放工具。任务没有固定请求次数、工具总次数或总时长上限，但连接超时15秒、读取无数据超时120秒；工具命令默认120秒，可按支持的参数设置超时。

## 上下文与引用

每次任务按读取权限加载有界项目概览、相关清单及规则。根目录、引用文件及成功探索到的目录和搜索命中路径适用 `AGENTS.md`，同目录优先于 `AGENT.md`；来源和子树作用域可查看。规则作为用户级参考，不能提升权限。读取为询问或禁止时不自动加载正文。

结构化写文件或创建目录前，若发现适用规则新增、变化或删除，先返回明确未执行事件，下一次请求收到更新后才可按原权限重试；审批等待结束也复核。超限或不可读提示不完整。任意 Shell 无法可靠推断全部修改目标，不具备同样的目标规则门禁。

输入框可引用文件或构建错误；编辑器可引用选区，无选区时引用当前文件。最多4项、每项6000字符，记录来源、行号、未保存与截断标记。引用是当时快照，不随磁盘自动更新；迟到读取不能附到另一项目或会话。

当前项目已加载编辑页签的未保存数量会提示给用户和模型，不附带未引用的缓冲正文。零个不证明不存在其他草稿；运行只使用磁盘源码，不自动保存。

消息 JSON 超过96k字符或96条消息，以及成功历史超预算前，使用当前模型生成有损续接摘要，保留当前需求及最近完整工具组。摘要消耗模型用量，本地保存；界面显示实际上下文字符和压缩次数。摘要失败保留进度并停止，不重放工具，也不产生授权。

## 权限与执行

权限按项目配置允许、每次询问和禁止，并支持单工具例外。默认只读工具和计划允许，写文件、创建目录与命令询问；长期允许副作用需额外确认。禁止优先，临时授权只对当前任务有效，不在重启后恢复。

审批可仅允许本次、当前任务同工具同目标，或当前任务同工具全部目标。写入可审阅草案 Diff；命令显示实际脚本、固定工作目录和共享 PRoot 环境边界。审批不代表命令安全或结果正确；PRoot 不是隔离恶意代码的安全沙箱，命令可能联网或访问其他挂载项目。

执行过程显示排队、审批、运行、成功、失败或未完成，可展开参数、授权来源、输出、退出码和耗时。模型计划与操作说明单独标识，不展示或编造内部思考；活动任务执行过程默认展开计划，其他页面和结束任务默认收起，可手动改变。

文件工具支持有界目录、字面搜索、行号、路径与 glob 筛选。UTF-8文件上限1 MiB、20000行、每行20000字符；`read_file`按字符offset/limit分段，每次最多64000字符，或用一基行范围，不能混用。分段不绕过整文件限制；`write_file`是全量替换。

路径穿越、符号链接、敏感路径、不支持编码、占用缓冲和基线冲突受保护。失败读取不建立新的写入基线；重读、冲突后重试仍遵循权限。可批准现有Ubuntu命令使用sed/Python处理文件，不增加宿主Shell通道。模型输出未完整接收的工具参数不执行。成功大文件写入的后续上下文保留路径、长度与SHA-256并明确省略正文，不能将摘要当成可重放写入；需要当前内容时重新读取。

命令前后另采集最多64个/256k字符的受支持文本，展示观测到的增删改；排除敏感路径、链接、生成物及超限内容，不保证归因于单一进程。此观察不是自动撤销承诺，恢复以持久检查点实际捕获范围为准。

## 会话与诊断

会话在应用私有目录按项目保存，首次发送前落盘，生成中约每750ms检查点，结束后保存。保存、切换和删除串行；临时保存失败可显式重试，损坏加载不能被静默覆盖。卸载或清除应用数据会丢失记录。

每项目最多20会话；每会话最多512条/512k正文字符及64条/512k工具记录。请求历史保留最近32次/768k请求与响应正文字符，会话JSON上限8 MiB。达到保留上限有提示，不是无限或不可篡改审计。

续聊成功原始历史最多8轮/96k字符，另保留最多4条/48k字符失败、停止或中断记录，含原需求、部分输出、工具结果与原因；显示的历史不等于全部发送。重启恢复已保存进度，未完成操作不会自动重放。未发送输入支持导航和Activity重建保留，不承诺冷启动磁盘草稿。

单次响应正文最多256000个UTF-16码元，Markdown预览预算64000；超出提供固定已接收快照的分页原文，关闭重开可读取新增内容。单个SSE事件8 MiB、累计工具参数8M字符、请求消息8M UTF-16码元；超限或模型输出截断会诊断，已接收部分不伪装完整。

“请求”页提供实际HTTP状态、稳定错误、耗时、首字延迟、事件/字节数、脱敏详情及时间线。Token只显示服务返回的usage，缺省标为未提供；实时字符曲线不是Token统计。原始认证头、密钥和服务异常原文不进入诊断记录。

## 页面与扩展入口

对话页只保留“对话、变更”两个常驻页签；请求诊断、验收、检查点和权限从标题更多菜单进入。设置中的“AI 扩展”集中管理 Skill 与 MCP，对话页提供数量摘要和快捷入口。返回扩展前后的未发送输入仍属于原项目、原会话；切换会话不会把选择合并到其他会话。

## Skill

在“AI 扩展 → Skill”查看当前项目与会话后选择指令。选择沿用会话保存，不改成所有项目共享的全局开关；活动任务期间不能修改。

内置13个离线手机适配指令，可搜索、查看、启停或恢复推荐。新会话推荐lean-build、surgical-patch、investigate-first、verify-and-stop、caveman；三种表达风格互斥，明确全部关闭后仍保留选择。

项目Skill位于 `.zakocoder/skills/<目录>/SKILL.md`，支持元数据、正文及配套文件。内置与项目合计最多启用16项/32k正文字符；只作为当前任务的用户级参考，不固化于成功历史，不自动执行脚本、提交代码或绕过审批。模型被要求首次采用时简短说明名称与用途；启用不等于实际采用。资产版本、摘要与许可见[来源清单](builtin-skills-provenance.json)及[第三方说明](../THIRD_PARTY.md)。

## MCP

“AI 扩展 → MCP”保存设备级服务配置，连接与操作绑定明确选择的项目。支持 Ubuntu stdio、Streamable HTTP 和旧 HTTP+SSE；协议协商支持 2025-06-18、2025-03-26 及旧 2024-11-05；不提供服务市场、自动安装、OAuth、sampling 或 elicitation。stdio 的命令和参数在当前项目 Ubuntu 工作目录执行，不在 Android 宿主 Shell 执行，也不占用四个可见终端名额。所需 Ubuntu 和服务依赖仍需显式安装。

可手填或导入标准 `mcpServers` JSON。配置保存在应用私有目录，以 Android Keystore AES-GCM 整体加密；参数、环境变量和请求头不会进入可恢复页面状态或项目导出。导入后停用，忽略导入的 `autoApprove` 授权；编辑保存同样先停用。保存不连接，启用、连接测试和模型实际调用分别处理。外部地址只允许 HTTPS，明文 HTTP 仅限设备回环地址；拒绝重定向和跨源旧 SSE 投递地址。

显式连接测试完成初始化和有界工具发现，展示工具描述与协议内容后关闭测试连接；“测试通过”不表示常驻在线或工具安全。AI 经 `use_mcp` 调用发现、工具、资源或提示，参数保留嵌套 JSON；默认询问，使用现有禁止、一次允许及任务授权策略。同工具同目标的 MCP 临时授权同时绑定服务、方法和完整参数，参数变化需重新审批。连接本身也可能启动程序或联网，读取资源和提示不隐式免审批。

服务返回是未受信任的参考数据，不能提升权限或要求绕过审批。结果中的 `isError` 保留并记为失败；错误、超时和停止不自动重试，远端可能已经执行的副作用不能由本地检查点撤销。任务结束、取消或停止全部关闭所属连接和 stdio 进程；应用重启不重连或重放调用。单次协议交换及首次初始化共享 70 秒截止时间，HTTP 连接 15 秒、读取无数据 60 秒；消息最多 2 MiB，目录最多 20 页、1000 项及 1 MiB 条目正文。请求有这些预算限制；目录截断有提示，不承诺无损无限审计。当前不支持断线恢复和事件重放。

## 修改审阅与恢复

变更以全屏只读Sora展示原文、修改后和Diff，并展示已知权限变化；仅权限修改明确正文未变化。历史变更读取持久检查点，绑定项目、会话与轮次；加载、失败、已淘汰与范围内无修改分开表达。

任务前建立有界检查点，工具后更新并封存。每项目保留最近5次，每次最多500文件、500目录，原始内容总计16 MiB、单文件1 MiB；排除敏感路径、链接、依赖和生成缓存。当前任务每轮可附最多32路径/8000字符条目的净变化元数据；读取权限不足不自动附加，失败为未知。它不是实时全盘扫描、AI归因或验证证明。

当前进程的文件工具修改可逐项撤销；历史检查点只提供其支持的整体恢复。恢复前整组核对内容、权限、编辑缓冲及原始快照，后续修改或未知结果阻止覆盖。目录可恢复缺失结构、空目录和权限；新增目录只在无未知子项时非递归删除，不支持自动恢复文件与目录类型替换。

恢复逐文件原子写入并持久记录进度，不保证跨文件事务；中断可重新审阅后确认，审阅后变化会拒绝。跨会话保留恢复事实，旧验证降为历史待重跑。并发终端变化可能被采集；依赖安装、网络、数据库、其他项目及未捕获文件不恢复。

## 运行、验证与续作

项目命令可配置脚本、相对cwd与1秒至24小时超时，默认30分钟。用户执行需确认；AI沿原工具审批。只有逐条原样匹配配置的脚本才归类构建/测试/运行，复合或改写脚本记普通命令，不凭文本猜测通过。

最近20次记录保留来源、轮次、脚本、状态、退出码、耗时与最多512k字符日志；新日志保留开头64k和末尾448k，中段省略有提示，约半秒落盘。支持搜索、分页、查看末尾及总计6000字符的带范围日志引用；引用保留未发送草稿，不自动请求。AI可审批后按run_id回查当前项目日志。重启未结束记录为中断。

退出码与当前源码适用性分开显示：有界字节/目录/权限摘要可表示范围未变、运行中变化、后续变化或未知；旧记录或受限采样保持未知。排除依赖、敏感文件和生成物，不证明整个环境；命令配置变化也需复核。验收手动重跑关联所选轮次，并明确来源是用户复核，不冒充AI执行。

服务应通过当前项目可见终端运行，最多共享4会话；跨项目不能控制。任务结束保留服务，关闭终端、停止全部或应用进程退出会停止。候选预览地址不证明就绪，需实际检查输出及访问结果；参见[运行环境](RUNTIME.md)。

### 移动端配置入口

底部“助手”进入原 AI 编码工作区，能力和会话存储不因改名改变。输入框下方模型选择器只读取本机配置摘要，切换不发送当前草稿；添加直接进入模型编辑，管理进入完整配置列表。任务运行或恢复期间不可切换。盾牌及默认权限文字进入当前项目策略，扩大授权仍需要原有确认；扩展图标进入 Skill/MCP 管理。上下文统计与数据发送说明在“更多 → 数据发送说明”，请求及验收仍有独立页面。

MCP 添加和导入保存均为显式操作，表单主按钮固定底部。高级配置折叠不会清除输入；编辑器返回不自动保存，也不会因展开、选择协议或切换页面而连接服务。
