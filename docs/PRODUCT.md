# 产品与能力边界

ZakoCoder 是处于 `0.1.0-dev` 阶段的独立 Android 原生 AI 编码工作台。目标是在手机上围绕真实项目完成需求、编辑、命令执行、变更审阅与验证；当前不作为生产就绪或完整桌面 IDE 的承诺。

## 核心流程

选择项目 → 安装所需环境与工具 → 配置模型 → 编辑或发起 AI 任务 → 审查授权与变更 → 执行项目命令 → 查看结果或恢复检查点。

项目可以是脚本、库、CLI、Android 或网页工程。类型识别只提供建议，不自动安装、构建或运行；手机端工具链兼容性仍由具体项目决定。

## 当前功能

| 范围 | 行为与边界 |
| --- | --- |
| 项目 | 搜索、创建项目（可选静态网页／Node.js／Python／C++／Go／Rust／Android Java/Kotlin/JNI 初始化模板，“其他”只建空文件夹）、SAF 导入私有工作副本、图形化选择真实本地目录绑定及导出新目录。导入不会自动同步原目录；绑定直接修改原目录，解除绑定保留源码，目录失效保留登记并报错。共享存储需系统文件权限，不支持云文档路径推断；导入导出跳过缓存、生成目录、`.git` 和符号链接，不是完整备份。 |
| 文件 | 新建、单文件导入、重命名、复制、删除和目录导航；同名拒绝覆盖，删除需确认。 |
| 编辑器 | Sora 原生编辑、常见语言基础语法着色、Markdown 编辑／预览切换、查找替换、撤销重做、最多 8 个缓冲区及显式保存；支持文件／选区引用到 AI；可选实验性 Python／JS／TS LSP 补全与诊断，需安装本机语言服务，暂不含 Java／Kotlin LSP 或完整重构。 |
| 草稿与冲突 | Activity 重建保留编辑状态；停止输入约 500ms 保存私有草稿，冷启动恢复文本与光标。保存比较磁盘基线，外部变化不覆盖缓冲；最后约半秒输入可能丢失。 |
| 环境 | 校验安装固定 Ubuntu ARM64 基础系统，独立工具包选择、真实探测和确认安装；Android 工具包支持基础 Java/Kotlin Debug 构建及调起系统 APK 安装器，可选 NDK 支持 arm64-v8a 的 CMake/JNI 模板；Compose／其他原生工程／Flutter 仍需适配。 |
| 项目依赖 | 根据根清单生成 npm、Python venv/pip、Go、Cargo、Gradle 计划，展示工作目录和命令，确认后安装并记录结果。嵌套工程及其他依赖需手动处理。 |
| 终端 | 默认空的会话卡片列表，最多 4 个真实 PTY；直接输入、辅助键、会话切换、Bash／可选 Zsh。返回列表保留进程，关闭会话终止所属进程。 |
| 预览 | 从终端输出选择或手填本机 HTTP(S) 地址，在系统浏览器打开；不扫描端口、不内嵌浏览器，地址出现不代表服务就绪。 |
| Git | 公开／私有 HTTPS 克隆，按项目及仓库来源加密保存访问令牌；状态、领先／落后数量、获取、快进拉取、显式推送、分支新建／切换／合并，以及冲突列表、编辑、确认暂存解决和中止合并。无强推、rebase 或 Git 专用 SSH 密钥管理；详见 [Git 工作流](GIT.md)。 |
| 设置 | 软件源、终端字体与默认 Shell、DNS、PATH、HTTP／SOCKS5 代理、下载缓存清理、通知状态及第三方许可。SOCKS5 支持可选用户名/密码（`socks5://用户:密码@主机:端口`），凭据用 Android Keystore 加密保存、界面打码，但配置认证后 guest 的 `ALL_PROXY` 会携带该凭据（对 guest 进程可见）。代理作用于环境镜像下载、AI 请求与新建 guest 进程。应用自身请求（镜像下载、AI 请求）经 SOCKS5 时把目标域名交给代理侧解析（SOCKS5 ATYP=3）；guest 只导出 `socks5://` 形式的 `ALL_PROXY`，curl／git 等工具在该 scheme 下本机解析，仅 `socks5h://` 才由代理解析（本项目不导出 socks5h）。apt 等仅识别 HTTP 代理的工具不会走 SOCKS5。 |

首次启动没有预置项目、会话、基础系统或模型密钥，不自动下载资源或请求模型。

## 本机 Git 与语言服务

Git 操作直接作用于当前项目目录，复用 Ubuntu 和 Git 工具包，不建立另一份源码副本。获取只更新远端记录；拉取默认仅快进，分叉时停止并提供明确合并流程。推送需确认远端与目标分支，不自动强推；领先／落后数量依据已获取的上游记录，不代表服务器实时状态。取消或超时后重新检查有界仓库状态，无法确认时停用依赖旧状态的操作；取消不能撤销已经发生的远端推送或本地合并。

私有 HTTPS 凭据按项目、来源与仓库路径绑定，使用 Keystore 加密并排除系统备份，不写入源码、远端 URL 或 AI 会话。已有 `ssh://` 远端使用 Ubuntu 中预先配置的 SSH 身份及已核对的主机指纹；HTTPS 令牌表单不配置 SSH，不自动信任主机，也没有 Git SSH 密钥管理界面。PRoot 不构成凭据隔离边界，同 UID 的获准命令仍可能访问短时认证文件。远端新增／编辑、rebase、Git LFS 和子模块管理仍需终端。

编辑器 LSP 通过 Sora 的实验性模块连接本机 Ubuntu 中的 Python 或 JavaScript／TypeScript 服务。依赖显式安装并访问外部软件源，不在打开文件时自动安装；服务可读取运行环境能访问的工程文件。当前可见文档持有连接，缓冲区变化参与诊断和补全，保存通知跟随显式保存；切换文件或离开编辑器会释放连接。诊断数量与状态可查看，失败可重试及查看有界本地诊断日志；诊断不是构建验收。暂不含 Java／Kotlin 服务、完整跨文件重命名和符号导航，项目依赖解析及设备兼容性以实际验证为准，见[语言服务](LSP.md)。

## AI 编码

模型配置支持命名配置、切换、模型发现／搜索与手填、可选生成参数、思考模式及推理强度、上下文 Token 窗口与自动压缩设置、自定义请求头及显式流式工具连接测试。参数仅在用户配置后发送，是否支持由服务决定。请求头值在本机加密，不回显；跨服务源必须明确清除或替换。模型生成请求支持有界暂态重试及每次尝试日志，不重放已执行工具，详见[请求重连](AI_WORKFLOW.md#模型请求重连)。支持 HTTPS Chat Completions、Responses、Anthropic Messages、Gemini 原生流式工具协议及常用服务预设；格式、参数及未覆盖项见[模型协议](MODEL_PROTOCOLS.md)。连接测试可能计费，不执行项目工具、不自动保存，也不代表完整任务兼容。

AI 可探索目录、读取和搜索文本、修改文件、创建目录、执行 Ubuntu 命令，并管理当前项目终端。单个活动任务按真实事件显示参数、审批、输出、退出码及耗时；模型公开计划与服务返回的 `reasoning_content` 分开显示；当前思考逐片展开更新，首段正文或工具调用开始后自动收起；历史可展开和复制，随历史保存。只展示服务公开返回的内容，不推断隐藏思考；超过展示保留上限时明确提示，复制仅包含已保留部分。终端工具与手动操作共享四个会话名额，不能控制其他项目的会话。

工具按项目设置允许、询问、禁止及单工具例外。普通权限沿用初始规则：安全只读与计划允许，写文件、创建目录、命令、终端／命令日志读取及 MCP 等操作询问。高权限需确认后保存为当前项目的持久规则，项目工具自动允许，MCP、Android 屏幕操作与 SSH 继续询问；两种预设均保留现有有效禁止项，高级逐工具规则可展开修改，非预设组合明确显示自定义。它不赋予 Android root 或系统文件权限。临时审批仍可限本次或当前任务范围，禁止优先。批准命令可能执行项目或依赖脚本，PRoot 不是安全沙箱，不能据项目工具边界推断命令被隔离。

图片可由系统选择器添加，与文字一起或单独发送。应用把支持的 JPEG、PNG、WebP 解码、处理方向并缩放为私有 JPEG 归档，历史保存引用与尺寸等元数据；请求时按选择的协议转换为 Chat `image_url`、Responses `input_image`、Anthropic image 或 Gemini inlineData，诊断不保存图片编码正文。模型必须支持视觉输入；当前已有兼容请求实现，尚未完成真实提供商的图片语义理解验证，文字连接测试不能替代视觉验收。图片费用及视觉 Token 以服务实际返回为准，压缩总结不保证保留全部视觉细节。具体导入、保留与省略规则见[AI 工作流](AI_WORKFLOW.md#图片输入与权限预设)。

项目规则、显式文件／选区／报错引用与有界项目概览参与上下文，自动读取服从工具权限。支持离线内置 Skills 及项目 Skills；可新建或导入单个 Markdown 文档、包含多个 Skill 目录及配套资源的 ZIP，保存至 `.zakocoder/skills/` 且不自动启用。按会话选择，内容仅为任务参考，不能提升权限或自动运行脚本。启用列表不等于实际使用记录，导入布局和限额见[AI 工作流](AI_WORKFLOW.md)。

“设置 → AI 扩展”集中管理 Skill 与设备级 MCP 服务。MCP 支持 Ubuntu stdio、Streamable HTTP 和旧 SSE，工具、资源及提示沿用项目审批；导入不继承自动授权，保存不连接。配置整体加密，外部返回是不可信参考，任务结束关闭所属连接，外部副作用不能由项目检查点撤销。协议版本及未支持能力见[AI 工作流](AI_WORKFLOW.md)。

会话和工具结果在本地有界保存；首次发送前落盘、执行中周期保存、结束时保存。失败或取消的已存进度用于续聊，不自动重放工具或恢复临时授权；已知保存失败可显式重试，损坏加载禁止覆盖。上下文接近可用输入预算时由当前模型生成有损摘要，会产生模型用量；默认窗口 128,000 Token、阈值 90%，先扣除输出预留。上下文显示为本地估算，计费用量以服务返回 usage 为准。支持手填及具体模型的参考窗口，不能突破实际服务限制，详见[模型上下文](MODEL_CONTEXT.md)。没有固定任务请求次数上限，但连接、空闲、命令及内存边界仍有效。

## 可选能力包

设置的“开发能力 → 能力包”和助手更多菜单共用管理入口。Android 屏幕识别与操作、SSH 远程开发是独立能力包，按项目保存启用状态且默认关闭。关闭时不加载该包的工具定义与专属提示；重新开启不继承已撤销的任务操作授权。能力开关不等于系统权限或操作审批，实际工具调用仍按项目规则询问，当前任务授权也不跨任务保存。界面规范见[能力包设计](CAPABILITY_PACKAGES_DESIGN.md)。

SSH 使用原生 JSch 客户端，不依赖 Ubuntu、PRoot 或手机内的 SSH 命令。每个项目配置主机、端口、用户、远程工作目录与密码／私钥认证，可选私钥口令和 tmux。首次连接在认证前探测并展示主机指纹，用户通过可信渠道核对；指纹变化会阻断继续，不能自动信任。连接配置、认证凭据和自有任务记录在设备 Keystore 支持的 AES-GCM 加密目录中保存，不属于项目导出或模型工具参数；界面不回填已存凭据。支持的密钥、交换及签名算法仍受 Android 安全提供者、JSch 与服务器配置共同约束，不能承诺所有平台或密钥格式兼容。

远程命令从所配置的工作目录开始，但该目录不是 Shell 沙箱；获批命令仍以 SSH 用户权限访问服务器。SFTP 文件工具限制相对路径、检查链接与已有文件摘要，采用同目录临时文件和重命名；服务端不提供完整的原子比较交换（CAS），最终复查与重命名间仍有竞争，不能保证排除外部并发写入，且覆盖已有文件需要相应服务器扩展。远程变更和副作用不在本地项目检查点的恢复范围内。

连接测试显示实际连接及 tmux 检测结果；验证成功不表示持续保持连接。停止会关闭当前所属连接，不保证服务器上已启动的后台进程退出。tmux 需远端安装并由用户选择启用；使用本应用所属的任务标识管理启动、列出、抓取输出、输入及结束，不接管用户其他 tmux 会话。断开后自有任务可保留，后续重新连接查看；远端重启、清理或任务自身退出仍会导致任务不可用。

## 变更、验证与恢复

文件变更可在全屏只读代码审阅中切换原文、修改后和差异。任务检查点持久记录有界文件与目录状态，重启后仍可审阅、恢复；缺失检查点、读取失败和记录范围内无变更分别显示。恢复检查后续内容、权限与编辑缓冲冲突；不覆盖未知改动，不保证跨文件事务或排除外部进程竞争。

文件变更列表独立展示会话、需求轮次与增删行数，检查点另有入口。可从所选轮次前分叉新会话，保留原会话及当前项目文件；分叉续接摘要有损，不代表文件也恢复至该轮。每轮用量仅汇总服务实际返回的 usage，缺失明确标记；任务结束保留耗时与完成时间，不把结束状态当作验证通过。

项目配置构建、测试、运行命令及相对 cwd、超时。结果根据实际脚本与配置精确匹配分类，真实退出码决定运行结果；模型结束、依赖安装成功或旧测试通过都不等于当前源码验证通过。日志和运行记录可引用到 AI，手动复核与 AI 执行保留来源区别。未保存缓冲不会自动保存或参与命令执行。

Android 工程需先在统一能力包入口为当前项目开启“Android 屏幕识别与操作”，再从包的配置面板选择 Debug APK，使用普通／无障碍／Root 三种屏幕测试方式。普通方式仅安装与启动；界面交互需单独授权。安装前后的包名、签名、调试标记与 APK 内容摘要必须匹配；相同版本号的旧安装包不能冒充当前构建。任务结束或停止会撤销目标和截图分享授权，保留有界本地报告。截图发送默认关闭，需用户单独确认。Root 不能扩大目标范围，Root 截图仍需无障碍服务；不同设备及系统版本的兼容性以实际验收记录为准。详见[屏幕测试说明](SCREEN_TESTING.md)。

安装包、网络、数据库及范围外文件等副作用不由检查点撤销。恢复文件后需重新验证；恢复操作不会改写原历史退出码。

## 数据与资源限制

| 内容 | 当前边界 |
| --- | --- |
| 编辑与结构化文件工具 | UTF-8，单文件 1 MiB、20,000 行、单行 20,000 字符；拒绝敏感路径和符号链接。更大文件可通过获批命令处理，但不扩大审阅与恢复范围。 |
| 引用与 Skills | 引用最多 4 项、每项 6,000 字符；Skills 最多启用 16 项、正文合计 32k 字符。 |
| MCP | 最多 32 个服务、配置明文合计 512 KiB；AI 包装调用参数最多 24,000 字符，单条协议消息 2 MiB；目录最多 20 页／1000 项／1 MiB 条目正文，超限或截断明确反馈。 |
| 图片 | 每轮最多 4 张；单张原始数据最多 12 MiB，导入后最长边 1600 像素、单张最多 1 MiB；私有归档最多 256 张／128 MiB。历史只保存元数据，缺失图片明确报错。 |
| 会话与回复 | 每项目最多 20 会话；单会话时间线最多 512 条／512k 正文与思考字符合计、64 条／512k 工具记录；单次回复正文最多 256,000 UTF-16 码元，长正文提供有界预览和分页原文。 |
| 上下文与本地容量 | 窗口可设 8,192–2,097,152 Token；最终请求体最多 32 MiB；连续协议上下文最多 10,000 轮、每轮 100,000 条消息、合计 24 × 1024 × 1024 个 UTF-16 码元。设备容量限制独立于服务窗口。 |
| 请求诊断 | 展示服务实际返回的 usage，缺失显示未提供；字符曲线不是实时 Token。最近最多 32 次／768k 请求响应正文字符，会话文件上限 64 MiB；不是无限或不可篡改审计。 |
| 检查点 | 每项目最近 5 次，每次最多 500 文件及 500 目录、原始文本合计 16 MiB；排除敏感文件、链接、依赖及构建缓存。 |
| 项目命令记录 | 最近 20 次，每次日志最多 512k 字符；新日志保留头 64k 与尾 448k，遗漏有提示。终端滚动缓冲不持久保存。 |

私有工作区、草稿、会话及日志位于应用私有存储，卸载或清数据会丢失；绑定源码保留在原目录，但绑定登记随私有数据丢失。项目导出不包含模型密钥，也不等于上述数据的完整备份。AI 任务所读取的项目文本及所附图片会发送至所配置服务；无账户体系、云同步或遥测。

## 已知范围

当前面向 ARM64 真机，minSdk 26 不代表最低版本与全部厂商设备已完成验证；x86_64 模拟器尚未适配。系统回收应用后不保证进程继续运行，也不自动重放任务。语言工具链、模型供应商、无障碍及新版 Android 生命周期需要持续补齐覆盖。

不包含通用手机自动化、模型本地推理、多任务调度、插件市场或后端。SSH 是按需连接用户已有服务器的开发能力，不提供托管远程工作机。后续方向见[路线图](ROADMAP.md)，运行与发布限制见[运行环境](RUNTIME.md)和[发布流程](RELEASING.md)。
