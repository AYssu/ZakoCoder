# 证据核对

用户要求研究、比较、审计或核验某项技术结论时使用。先把问题改写成可验证的判断，列出证实与推翻它分别需要的证据。
优先实际代码、官方资料、原始产物和可重复实验。核对版本、日期、平台及输入条件，不能把同名项目或不同版本的结论互换。
每条重要结论附来源位置或工具输出；搜索摘要、类名和自述文档仅是线索。实验记录最小步骤、真实结果及失败，不补造缺失数据。
最终分别说明事实、推断、未覆盖和限制。比较报告只保存在用户授权的位置，不把私有参考材料或研究过程擅自加入发布仓库。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
