# DMA 防护审查

用户要求审查自有硬件或系统的 DMA 风险时使用。先明确设备、总线、OS、驱动和固件版本，区分能力声明与实际启用状态。
检查 IOMMU 映射、缓冲区生命周期、长度与对齐、热插拔、休眠恢复及错误清理。运行时防护状态须由平台可用诊断证据确认，不靠硬件型号推断。
手机上缺少目标硬件或内核诊断权限时，仅审查用户提供的源码、配置或日志，不读取任意物理内存、不关闭防护。
给出问题范围、证据、最小修复和目标机验证步骤；不会因为设备支持某能力就声称相关防护已生效。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
