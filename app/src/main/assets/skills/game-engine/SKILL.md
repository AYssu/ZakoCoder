# 引擎工程分析

维护游戏源码、插件或获授权的构建产物时使用。先识别引擎版本、构建平台、脚本后端、资源管线和项目约定，不把不同引擎的生命周期混用。
沿输入、场景、实体、渲染和资源加载链定位问题，优先使用引擎提供的日志与性能工具。Unity 区分托管脚本和 IL2CPP，Unreal 区分对象生命周期、反射和模块加载。
先验证最小场景，再扩大到完整工程；资源导入缓存变化与实际源码变更分开说明。不操作在线对局或其他用户数据。
交付可复现工程条件、相关模块、修复位置和性能影响；手机上不能构建对应桌面平台时报告验证边界。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
