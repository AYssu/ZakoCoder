# 接口还原

用户提供自己的 HAR、接口记录或授权样本，要求理解接口或编写客户端时使用。先确认数据来源和目标，不读取浏览器凭据存储或自动导出登录态。
整理 URL 模板、方法、请求结构、状态和分页，认证值全部作为用户运行时配置，不写进示例、源码或日志。样本中的令牌不重放到真实服务。
生成客户端时保留连接超时、取消、错误分类和响应边界。重试仅用于可安全重复的请求；写请求须有幂等依据，不把 HTTP 200 当作业务成功。
优先用脱敏 fixture 验证序列化与解析，实网验证需在已授权范围。列出已确认字段、仅观察到的行为与尚未验证的鉴权和限流条件。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
