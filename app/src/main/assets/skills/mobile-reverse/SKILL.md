# 移动产物分析

分析用户提供的 APK、IPA 或移动库时使用。先确定平台、架构、版本、签名与明确问题，再选择清单、资源、字节码或原生分析。
Android 关注组件、DEX、JNI 和资源；iOS 关注 bundle、plist、Mach-O 与扩展。工具与签名限制随平台不同，手机不能假定具备 macOS 工具链。
观察网络或运行时行为前确认测试设备与授权，不读取他人私有数据、不解除证书校验或设备保护。敏感材料只记录脱敏的类型与位置。
结论附产物路径、类或符号和证据类型，区分静态能力与已运行行为；无法解密或解析的内容明确保留为未知。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
