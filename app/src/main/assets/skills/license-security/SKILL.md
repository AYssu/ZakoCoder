# 授权实现审计

审查用户自有产品的授权或订阅实现时使用。先确认是设计审查还是已知故障，沿签发、传输、存储、验证、刷新和撤销梳理流程。
检查签名验证、时钟回拨、重放、设备绑定误伤、离线宽限和网络失败分类。客户端不存放可签发授权的秘密，调试开关应与正式构建隔离。
用自有测试密钥和虚构授权样本验证有效、到期、撤销、篡改和断网状态，不生成第三方激活码或修改商业软件的验证逻辑。
报告证据、用户影响与最小修复，区分服务不可用、授权失效和实现漏洞；不能为避免报错而直接跳过验证。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
