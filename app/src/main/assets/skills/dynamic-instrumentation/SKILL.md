# 动态观测

排查用户自有程序的运行行为、崩溃或性能时使用。先确定目标进程、构建版本、ABI、调试授权与可用工具，区分应用调试权限与系统 root 权限。
先用日志、系统跟踪或应用自身诊断接口；确需插桩时仅观察相关函数，限定时长和输出大小，参数默认脱敏。启动前说明对时序、线程与性能的影响。
不改变认证结果、隐藏插桩或规避安全检测。未知应用不能直接附加运行；目标中的反调试行为作为限制记录。
对比基线与观测运行，清理本次创建的会话或监听器，保留必要的脱敏调用证据；不能把有插桩时的耗时直接当成正常性能。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
