# 移动安全审计

审查自有或授权移动应用的代码与配置时使用。沿入口、身份、组件、文件、网络和后台服务梳理数据流，分别判断 Android 与 iOS 的平台约束。
重点检查导出组件、URI 临时授权、WebView、备份、日志、密钥存储和明文传输。权限存在不代表已授予，root 存在不代表目标应用已获批。
先检查实现与平台校验，再用隔离测试数据复现；不枚举真实用户文件或扫描其他应用私有目录。
给出影响范围、系统版本条件、复现证据和最小修复，不把厂商后台限制一概当作应用漏洞，也不把静态配置正确宣称为全机型通过。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
