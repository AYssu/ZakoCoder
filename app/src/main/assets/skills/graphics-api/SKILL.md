# 图形接口分析

排查自有应用的 OpenGL、Vulkan 或其他图形接口问题时使用。固定设备 GPU、驱动、接口版本、构建和最小场景，先确认设备支持的功能。
按资源创建、提交、同步与销毁追踪，检查线程上下文、缓冲生命周期、布局转换和内存可见性。帧时间与 CPU 时间分开测量，避免把日志耗时当 GPU 耗时。
验证工具和图形捕获支持需实际检查，手机不假定具有 DirectX 或桌面捕获器。截图只能证明画面状态，不能证明帧率稳定。
输出触发场景、相关调用、错误或校验层证据及最小修复建议，不插入未经授权的外部进程覆盖层。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
