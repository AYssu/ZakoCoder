# 二进制分析

分析本地二进制结构或编译兼容问题时使用。先识别格式、架构、位数、端序、链接器、依赖和摘要，区分文件偏移、虚拟地址与运行时地址。
从节区、段、导入、导出、符号和字符串交叉定位目标。字符串只说明字节存在，不能单独证明功能被调用；跟进引用和控制流，标注无法解析的间接调用。
使用已安装且适合架构的分析器。未知程序先静态分析，不用运行目标来获取版本。不覆盖原文件，不对可执行区域自动打补丁。
输出可复核的地址、偏移、调用关系和工具限制；若因壳、加密或符号缺失无法确认，明确下一步需要哪类证据。
