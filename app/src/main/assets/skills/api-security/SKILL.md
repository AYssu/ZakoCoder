# 接口审计

审查用户指定的接口代码或获授权的测试接口时使用。先追踪请求路由、身份来源、对象归属、校验和返回字段，确认现有防护后再判断问题。
优先检查对象级与字段级授权、分页与资源上限、重复提交、错误响应、跨源认证转发和日志泄露。GraphQL 还检查解析深度，WebSocket 检查握手及每条消息的权限。
用本地测试或用户提供的测试账号构造最小对照请求，只请求必要字段，不遍历真实用户数据。不自动扫描外部地址或开展口令猜测。
按触发条件、实际影响、文件位置、复现证据和修复建议汇报；未测试的接口单独列出，不能仅凭 HTTP 状态推断认证正确。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
