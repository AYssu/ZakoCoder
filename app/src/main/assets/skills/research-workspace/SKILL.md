# 实验工作区

需要反复分析产物、比较版本或验证技术问题时使用。沿用用户指定目录，确认原件、临时输出与可交付结果的位置，不擅自创建新的产品模块。
输入只读保存并记录摘要，所有格式化、提取和测试写入独立副本。脚本说明工作目录、依赖、输入输出和退出码，失败保留必要证据而非假装空结果。
临时截图、日志与外部参考不加入发布源码。清理只针对本次明确创建的临时文件；删除前核对路径，不跟随符号链接，不清理用户原有资料。
交付最小复现步骤、结果索引及未完成项。仅创建目录不等于完成研究，也不自动开始下载、网络扫描或执行未知样本。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
