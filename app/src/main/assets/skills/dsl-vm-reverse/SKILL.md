# 虚拟机分析

用户要求分析自有程序或授权样本中的 DSL、自定义字节码或解释器时使用。先固定输入样本与解释器版本，定位加载器、分派循环、寄存器或栈及指令指针。
为已确认的操作码记录编码、操作数、栈变化、异常和跳转。用小型已知输入比较执行前后状态；一个样本不足以推广所有指令语义。
把确定语义与候选命名分开，保留原始字节与偏移。若需要跟踪运行，使用可丢弃副本和获授权环境，不执行未知字节码到真实业务数据。
交付指令表、可复现样本和仍未确认的分支；不因局部成功宣称已经完整还原虚拟机。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
