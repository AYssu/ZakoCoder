# 驱动代码审查

分析自有驱动源码、崩溃转储或授权样本时使用。先确认 Windows 版本、架构、驱动模型、构建符号和问题范围；Android 终端不能执行 Windows 内核测试。
检查 IRQL、锁顺序、分页内存、对象引用、IRP 完成、IOCTL 输入和卸载路径。用户态地址和长度必须按入口语义验证，异步请求需追踪生命周期。
使用用户提供的符号、转储或远端工具时固定对应版本，无法解析的栈帧保留未知。没有受控测试机时只做静态判断，不报告驱动已加载通过。
只对指定工程提出最小修复和测试建议，不提供隐藏进程、关闭安全监控或未授权内核修改流程。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
