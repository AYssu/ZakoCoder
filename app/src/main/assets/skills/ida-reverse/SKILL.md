# IDA 分析协作

仅在用户指定 IDA 分析任务且当前已有对应工具或用户导出材料时使用。先确认目标摘要、处理器、映像基址、数据库与版本；没有 IDA 时不伪造远程实例。
从明确的函数、字符串或地址出发，结合调用者、交叉引用和反汇编验证伪代码。区分代码地址、数据地址与文件偏移，保留函数签名和地址来源。
符号重命名、类型应用和数据库保存都是修改；未经授权先输出建议。不能把会话中的数据库改动当成原二进制已修改。
结论附地址和关联调用证据，列出未解析的间接分支、混淆和工具限制；不要将完整商业数据库或私有样本上传到额外服务。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
