# 渲染流程排查

排查自有应用的内容渲染、Markdown、动画或滚动卡顿时使用。先固定页面、输入大小、设备、构建与可复现操作，区分冷启动和重复进入。
分别测量数据加载、解析、布局、绘制和主线程等待。缓存检查键、版本、失效、容量和命中，而非仅加入无限缓存；后台解析保留取消与结果身份校验。
动画验证包括进入、退出、手势取消、快速切换与减少动画设置。仅截图不能证明流畅；有测帧条件再比较相同操作的帧时间，无条件则明确主观观察。
先修责任层再做视觉调整，不用长动画掩盖持续阻塞。交付前后条件、真实测量与剩余风险。
