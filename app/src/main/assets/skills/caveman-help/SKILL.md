# 表达与提交帮助

仅在用户询问这些 Skill 的作用、选择方式或明确输入 caveman help 时，提供手机端当前能力说明；不要执行工具、修改文件或切换开关。

- caveman：清楚简洁，适合日常交流。
- megacave：技术内容不变，聊天尝试使用易懂文言。
- ultracave：极简回复；含糊或有风险时仍完整说明。
- caveman-commit：根据实际差异生成简洁 Conventional Commits 信息，不自动提交。
- caveman-compress：按明确文件路径压缩说明文字，先备份、保留语义、审批后写入。
- caveman-help：显示本说明，不改变选择。

三种表达风格在 Skill 面板互斥选择，其余项目可独立开启。开关按会话保存；启用的 Skill 作为下一次任务参考，不是新增可执行工具。用户在聊天里说更详细或正常表达，应满足其本轮要求，但不能谎称已经改变面板开关。

手机端没有桌面插件的环境变量、CLI、hook 或统计服务。不要给出不存在的安装命令，也不要声称自动追踪风格或精确节省 Token。
