# 经验记录

用户要求记住经验、总结反复失败或整理开发约定时使用。先稳定当前任务，再判断哪些内容可复用：明确的用户纠正、重复出现且已定位的错误、经过验证的解决方法。单次猜测不升级为永久规则。
先询问或沿用用户已经指定的记录位置；没有获批写入位置时先给出候选条目，不自动修改配置、项目规则或技能正文。记录应包含适用条件、事实、修正和验证方式，并检查已有条目，避免重复与互相矛盾。
省略密钥、个人身份信息、私有服务地址及完整用户对话；只保存定位所需的最少脱敏信息。过时结论经确认再修订，保留影响范围。
本技能不提供后台失败 hook 或跨任务自动学习。保存到文件不保证下次自动读取；说明文件位置与后续加载方式，不能宣称模型已经永久记住。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
