# 安全回归

用户授权对自己的源码或测试环境进行安全验证时使用。先固定范围、测试账号、数据与成功条件，优先本地 fixture，不自动扩展到外网扫描。
按已知风险检查权限边界、输入长度、路径、编码、并发和失败恢复。每个测试只改变必要条件，避免不受控请求量和破坏真实数据。
发现问题后记录最小输入、实际响应与影响；修复后重复相同用例并检查相邻正常行为。停止条件是验收项完成或出现需要重新授权的副作用。
报告通过、失败、跳过和未覆盖；没有发现不等于全面安全，不自动安装攻击工具、获取凭据或维护远端访问。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
