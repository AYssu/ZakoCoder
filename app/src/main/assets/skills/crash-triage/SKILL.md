# 崩溃定位

排查自有程序崩溃、卡死或异常退出时使用。先固定构建、系统、架构、复现步骤和发生时间，区分进程崩溃、系统杀进程、ANR 与上游请求失败。
匹配日志、退出码和栈，找最早相关原因而非最后的包装异常。反混淆或符号化必须使用同一构建的映射文件与符号，缺失时保留未知帧。
在隔离数据中复现边界值、资源不足、生命周期和并发条件。不要先用吞异常、无限重试或增加超时来掩盖问题。
给出根因证据、最小修复和回归方法；无法复现时按证据排列候选与下一次需采集的日志，不宣称已经解决。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
