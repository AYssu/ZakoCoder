# 内存与转储分析

用户提供自己程序的转储或要求排查内存问题时使用。先记录平台、ABI、构建、符号与转储类型，确认是否包含完整内存以及敏感信息。
从崩溃线程、栈、寄存器、分配统计和对象关系缩小范围。地址必须对应同一构建与进程快照，不把偶然残留字节当作有效对象。
读取转储只提取必要片段并脱敏。动态采样须经目标进程授权，避免读取其他应用、密码或会话数据；样本隔离保存，不上传额外服务。
结论区分直接证据与候选根因；给出复现与验证修复的条件，不以一次采样证明不存在泄漏。
