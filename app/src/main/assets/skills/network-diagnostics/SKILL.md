# 网络诊断

用户要求排查连接、下载、代理或接口超时时使用。先确认发起请求的是 Android 应用、Ubuntu 终端还是 SSH 远端，各自的代理、DNS 与证书配置分别验证。
从目标域名、解析结果、端口连接、TLS、HTTP 状态逐层定位。请求设置连接与总超时，优先最小只读请求；代理对照需明确直连和代理路径，不暴露代理凭据或订阅地址。
证书错误不能用关闭验证作为长期修复。代理连接成功不等于流量经过代理，应对照实际出站结果和协议日志；不要改设备全局路由来做无关探测。
按证据给出失败层、可复现命令、已排除项及下一步。没有外网验证条件时保留未验证状态，不用缓存结果伪装现场成功。
