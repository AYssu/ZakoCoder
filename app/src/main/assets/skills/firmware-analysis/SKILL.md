# 固件分析

分析用户提供的固件或升级镜像时使用。先记录型号、硬件版本、镜像摘要与容器格式，区分打包头、压缩区、文件系统和签名材料。
用已安装的静态工具查看分区和挂载结构。提取到新的临时目录，设置体积和深度边界，警惕路径越界、链接与解压膨胀。不挂载为可写，不执行提取出的安装程序。
审查升级完整性、默认配置、组件版本和暴露服务时只报告脱敏证据；版本号提示需要核实，不能仅凭版本断言存在漏洞。
不刷写设备或连接未知硬件。需要仿真或真机验证时列出架构、设备条件、数据备份和明确待验项。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
