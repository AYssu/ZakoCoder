# 环境体检

用户要求检查开发环境、工具缺失或 MCP 连接问题时使用。先确定当前工作区、设备架构以及是在 Android、Ubuntu 还是 SSH 远端操作，分别检查，不能混用一个环境的结果。
列出本次任务需要的工具，而非扫描整台设备。通过获批的终端命令先检查命令是否存在，再执行有界的版本或最小功能检查。区分：未安装、存在但无法执行、可以执行但业务链路不可用。保留退出码和关键错误，检查架构、动态链接器、证书、DNS、目录权限与进程工作目录。
MCP 是否可用以本次可用工具及连接测试为准；若未授权连接或没有对应工具，说明未验证，不把配置存在当作连接成功。不要读取凭据文件或打印请求头。
给出已验证项、缺失项、失败链路和最小修复顺序。安装、换源和修改网络配置沿用既有审批；不要为了体检自动安装一整套工具。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
