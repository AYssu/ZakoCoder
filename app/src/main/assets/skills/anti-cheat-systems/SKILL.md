# 游戏完整性设计

审查用户自有游戏的完整性保护或误报问题时使用。先确定客户端与服务端职责、威胁模型和可收集数据，不把单一客户端信号当作可靠裁决。
检查服务端权威状态、输入校验、重放保护、异常检测及申诉证据。区分调试、无障碍、驱动兼容和真实异常，评估权限、耗电及隐私成本。
在自有测试环境验证检测规则与误报，不操作第三方游戏、不隐藏调试器或编写检测绕过流程。
输出可解释的规则、测试条件、误报边界和回退策略。若没有代表性测试集，不以少量样本宣称准确率或全场景有效。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
