# .NET 分析

分析用户提供的 .NET 程序集或 C# 发布包时使用。先检查 CLR 元数据、目标运行时、依赖、资源和摘要；NativeAOT 产物使用原生分析路径，不能假定保留 IL。
从入口、类型、方法和 IL 调用关系定位目标，保留完整签名以区分重载。反编译出的 C# 只作重建视图，异常处理和状态机行为以 IL 为证据。
不加载未知程序集到宿主 CLR 来枚举类型，避免触发初始化或依赖代码。手机上缺少合适的元数据分析器时说明限制，不声称拥有 dnSpy 等桌面环境。
给出目标方法、调用链、依赖缺口和不确定部分；授权或许可证逻辑只分析设计与缺陷，不自动修改验证结果。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
