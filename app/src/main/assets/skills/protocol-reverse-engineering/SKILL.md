# 协议分析

理解自有协议或授权抓包时使用。先固定样本来源、版本、方向、传输层和是否完整，敏感请求头、账号及载荷先脱敏。
按帧边界、长度、端序、字段、校验和、分片与会话状态分析。区分原始字节、解析结果和推断命名，用多个样本对照确认，避免从单包猜完整协议。
构造本地离线解析器或模拟端验证，保留畸形帧、边界值和未知字段测试。不把截获的认证材料用于重放真实业务请求。
交付字段表、偏移、状态转换和未确认条件；协议兼容性必须由版本间样本或真实测试支撑。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
