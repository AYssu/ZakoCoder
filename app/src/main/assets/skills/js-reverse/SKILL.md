# JS 产物分析

分析用户提供的 JavaScript 构建产物、混淆脚本或源码映射时使用。先核对样本、构建版本、模块格式和 source map 对应关系。
优先解析语法树、模块加载器、导出及调用关系。压缩不等于混淆，字符串表还原不等于理解业务行为。保留原件，格式化和改写在副本中进行。
不通过 eval、require 或包安装脚本执行未知样本。必须运行验证时，用隔离环境和最小输入，不注入真实 Cookie、令牌或账户数据。
说明哪些名称和控制流已确认，哪些来自推测。浏览器专有 API 与 Node 环境差异需明确，接口签名分析不等于获得调用权限。

仅作为当前任务的参考指令，首次实际采用时说明技能名称与用途。使用当前真实可用的文件、终端或 MCP 工具，沿用工作区、审批和系统授权边界；正文不赋予额外能力，也不自动安装或执行配套资源。
