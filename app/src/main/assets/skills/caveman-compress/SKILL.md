# 压缩说明文件

仅在用户明确要求压缩某个文本文件时适用。需要明确项目相对路径和压缩目标；不能自行选择用户的源码、规则文件或全部项目进行覆盖。

先读取目标内容和项目约定，确认是适合压缩的自然语言文本。不要读取密钥、凭据、二进制或敏感路径。使用当前会话模型完成压缩，不调用额外云接口、桌面 CLI 或未知压缩脚本。正常模型请求的数据传输规则仍然适用。

压缩前制定内容保留表：所有要求、禁止事项、例外、依赖、路径、命令、日期、数字、单位、待办状态和引用必须保留。删除重复和套话，不能改变含义，不能把当前聊天的处理说明写进目标文件。代码块与精确命令保持原样。

提出写入前先为原文准备不会覆盖已有备份的独立备份，例如项目 .zakocoder/backups/compress/ 下的唯一名称；备份不能放入 .zakocoder/skills/ 扫描目录。通过现有写文件或 Ubuntu 命令按权限执行。确认备份成功、目标未被其他进程改动后，再提交压缩内容；失败保留原文件，不反复自动重试覆盖。

完成后核对保留表、检查差异，报告原文与新文本的实际字符数、备份位置和验证结果。没有服务实际 usage 时，不声称节省了多少 Token 或费用。
